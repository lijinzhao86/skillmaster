# SkillMaster

查和调的做法在技能描述里，不用读这里。这一份是**索引**：先看下面的模型和规矩，再按任务读对应的 SOP。

## 模型：skill 是由版本组成的

- 一个 skill 有若干**版本**，每一版有一个**版本码**。
- **线上（live）** 那一版才会被别人搜到、调用。
- **草稿（draft）** 默认只有作者看得到；共享给 `write` 及以上档位的人也能看（看草稿要 `write` 档）。
- **上线只能在网页上由人点。** CLI 里的同名命令不执行动作，而是打开那一页并说明「还没执行」——正常交接**退出 0**；档位或状态不对时**不开页面、退出 1**，照它的原因说给用户，那不是命令坏了（ADR 0126）。API 平面上没有这条路由。
- **删除有一个例外**：从没上线过的 skill 可以用 `skmr skill delete <地址> --yes` 真删；上线过的仍去网页（ADR 0127）。

每条 SOP 都收在同一句话：**「这是草稿，上线要你自己去网页上点」**。
