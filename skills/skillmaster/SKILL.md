# SkillMaster

**没有 `skmr`**：先照 https://dl.skillmasterai.com/beta/skillmaster.md 装，装完再回来——下面每一步都要用它。

**第一次用**：运行 `skmr startup`，主线大约 10 分钟走 3 块——找一条公开技能加进库用一次；做一条自己的（从头写或从本机导入）并发布上线；电脑上原来有技能的话，最后还能选择一起搬进来。也可以直接跟 Agent 说「带我走一遍 SkillMaster 的新人引导」。

加载后分两路：**对 skill 做操作**，还是**找一个 skill 来用**；都不是（问 SkillMaster 本身、问怎么装）→ 走前者。

搜索、加载、读取可以直接做；**改 skill 之前**先拿说明，不要凭记忆敲命令。

## 对 skill 的操作

新建、读自己 skill 里的文件、写、改、传、共享、看版本、丢弃、删除、装客户端、排障——先加载指南：

```bash
skmr skill invoke skillmaster/skillmaster-guide --yes
```

官方地址，不用先问用户——直接带 `--yes`（只对这一次生效）。照它说的做；参数用 `skmr <子命令> --help` 查。**加载不了**就用 `skmr help` 和现场报错继续，别自己编。

## 找一个 skill 来用

**1. 搜索。** 每个意图压成一句「这一步要做的事」，单独搜一次——别堆关键词：

```bash
skmr skills search "<一句话说清要做的事>"
```

默认只搜自己的库；用户明说「搜公开库」或「去公开库找」才加 `--scope public`。搜到的公开 skill **加载前先问用户**；同意后带 `--yes` 调用一次，想以后不再问就用 `skmr skill join <地址> --yes` 收进库。`skillmaster/` 开头的官方技能不用先问——直接带 `--yes`。

`skmr` 报错（没装 / 没登录 / 连不上）就直说「技能库暂时查不了」，按常规能力继续，不假装查过。

任务换段或压缩之后，**即使之前搜过，也重新搜**——加载过不等于做过。

**2. 判断。** 结果是候选列表，每条一句简介——**列在这里不等于用得上**。只留正在教「这一步要做的事」的：

- 有几条 → 都留下
- 一条都没留下 → 先换一种说法再搜一次；第二次仍然没有，才说这个意图不用 skill、自己做

**3. 规划。** 动手前把计划回复给用户，一行一个子任务：`意图 → 子任务 → 要加载的 skill`，例如 `写发布说明 → 起草变更条目 → yysstt/skill-creator`。没匹配到 skill 的子任务不列。

- 多个意图都有匹配 → 列一份待办，到每个子任务先加载再动手
- 全都没有 → 明说「这次不用 skill」，改用其它工具做

**4. 加载。** 到子任务前先加载：

```bash
skmr skill invoke <命名空间>/<名字>
```

同一个 skill 要接着读别的文件，用 `read`：

```bash
skmr skill read <地址> <相对路径> [--limit <行数>]
```

`read` 只读、不钉版本；要「加载来用」走 `invoke`。

**裸地址读 `SKILL.md` 会被拒绝**：正文就是 skill 本身，`read` / `cat` / `head` / `tail` 在地址没写版本、本机也没 `invoke` 过时一律退出 2，提示先 `skmr skill invoke <地址>`。`invoke` 之后或地址里写了 `@版本`，照常读。

加载后照它说的做，包括它给的 `skmr` 命令。

## 卡住了

命令持续失败、或文档与 `--help` 都解决不了时，把问题交给平台：

1. 运行 `skmr feedback template` 拿模板；
2. 写一份反馈文档，**先把完整内容给用户看并得到同意**；不要写密钥、密码、私有代码、他人的个人信息或对话全文；
3. 用户贴了图片或视频时，把附件一起带上——**不要让用户手敲 CLI**：
   - 消息里已有文件路径（如 `[Image: source: …]`，或拖进来的文件带出的路径）→ `skmr feedback attach --copy <路径>`；
   - 没有路径 → `skmr feedback attach --last-paste`（先找当前会话的粘贴缓存，再读 macOS 剪贴板）；
   - 还取不到 → 请用户把文件拖进对话（终端会带出路径），或另存为文件后告诉你路径。
   拿到路径后，图片用 `Read` 看一眼，确认是用户说的那张；视频按文件名和预览让用户确认（`Read` 不能渲染视频）；
4. 运行 `skmr feedback send --file <文件> [--attach <附件路径>] --consent`，把回执号告诉用户。

不带 `--consent` 只预览、不发送；预览会把附件清单给用户看、等用户确认后再加 `--consent`。图片或视频不会被自动扫描，画面里的密钥、个人信息与他人隐私要由用户自己确认；图片或视频还可能含位置等元数据。用户要撤回时运行 `skmr feedback delete <回执> --yes`。
