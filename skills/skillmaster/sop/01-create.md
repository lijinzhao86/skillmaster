# SOP · 新建一个 skill

从零建出来，直到把上线交到用户手上。

## 一、建出来

```bash
skmr skill create <名字> --description "<一句话>"
```

它打印**地址**和**版本码**。名字只用小写字母、数字、连字符。

## 二、写 SKILL.md

第一次写入必须带 `--name`。`--name` 是**这一版叫什么**，不是文件路径：

```bash
skmr skill write <地址>@<版本码> SKILL.md --name "<这一版叫什么>" < ./SKILL.md
```

## 三、其余文件

用**同一个版本码**继续写，一个文件一条命令。

草稿还没上线时要再改它（加文件、改内容、整份重写），按
[`03-edit-draft.md`](03-edit-draft.md) 做——它讲的就是「在已有的草稿上继续改」。

## 四、查相对引用

```bash
skmr skill check <地址>@<版本码>
```

全部成立时它什么都不打印、退出 0；断链会一行一条列出来。

## 五、交给用户上线

```bash
skmr skill open <地址> --tab versions
```

打不开浏览器就加 `--print`，把地址发给用户。

## 做完的标志

版本码有了、文件齐了、`check` 退出 0、你说了「这是草稿，上线要你自己去网页上点」。
