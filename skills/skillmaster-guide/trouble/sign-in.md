# 登录不上

> **先跑 `skmr auth status`**，按它说的那句分诊：「本机没有凭据」是没登录过或被清掉了；「凭据不可用」是有凭据但服务端不认；报出账号则说明命令行没问题，问题在别处。

**症状**：`skmr login` 报错，或者 `skmr auth status` 说本机没有凭据。

## 登录报错怎么找

| 现象 | 原因 | 怎么做 |
|---|---|---|
| 本机没有凭据 | 没登录过，或凭据被清掉了 | 跑 `skmr login` |
| 这份凭据已经被结束 / 已经过期 | 被撤销或过期了 | 重新 `skmr login` |
| 连不上 SkillMaster | 网络或服务地址不对 | 检查网络与地址后重试 |
| 浏览器里没有同意 | 授权页被关掉或点了拒绝 | 重跑 `skmr login` |
| 登录试得太频繁 | 触发了限流（登录频率限制） | 等一会儿再试 |

## 确认登录好了

`skmr auth status` 打印出账号名。

## 排查登录问题时要注意的

- **命令行没登录，和浏览器有没有登录无关。** 网页上好好的，命令行照样可能没有凭据。
- **登录成了另一个账号**：多半是浏览器还停在旧账号上，授权页用的是它的登录状态。先换浏览器，再 `skmr login`，见 [凭据](../account/credentials.md)。
