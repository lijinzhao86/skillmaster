# 加载不了、读不到

> **先分清三件事**：地址写错 / 你没有权限 / 这一版读不到。前两件查地址与档位，第三件查版本。

```bash
skmr skill versions <地址>
```

**症状**：`skmr skill invoke`、`read`、`ls` 报错，或者拿到的内容和预期不一样。

## 加载报错怎么找

| 现象 | 原因 | 怎么做 |
|---|---|---|
| 找不到这个 skill | 地址写错，或它是私有的、别人看不到 | 用 `skmr skills list` / `search` 核对；私有的请所有者共享 |
| 你对这个 skill 没有这个权限 | 档位不够 | 见 [共享给某个人](../ship/share.md)，或自己申请 |
| 这个 skill 还没有上线版本 | 只有草稿 | 请有权限的人上线；或按下面的办法读草稿 |
| 凭据已经被结束 / 没有凭据 | 登录失效 | `skmr login` |

## 内容像是旧的

裸地址用的是你**上次 `invoke` 时定下的那一版**；没 `invoke` 过才用当前线上。

## 读草稿

要把 `@<版本码>` 写进地址，而且**草稿需要「写入」及以上**才读得到——只有「调用」档的人读不了草稿。

## 排查加载问题时要注意的

- **`read` 和 `invoke` 不是一回事。** 读到了内容不等于这个 skill 已生效，见 [读一个 skill 里的文件](../use/read-files.md)。
- **网络问题、登录问题不是这篇的事**，见 [登录不上](sign-in.md)。
