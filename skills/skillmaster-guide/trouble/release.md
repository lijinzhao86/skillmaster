# 上线不了

> **先确认这一版真的存在、仍然是草稿**——页面上找不到某一版，八成是因为它已经上线或被丢弃了。

```bash
skmr version list <地址> --status draft
```

**症状**：`skmr version publish` 打开网页后找不到能点的地方，或者点了出错。

## 上线报错怎么找

| 现象 | 原因 | 怎么做 |
|---|---|---|
| 页面上没有「上线」 | 档位不到「维护」 | 请所有者或有「维护」的人来点 |
| 需要指定版本号 | 基线是预发布，或线上那一版不是合法号 | 在确认页上自己敲一个号 |
| 提示这一版已经上线 | 它不在草稿状态 | 刷新页面，确认你在看的是哪一版 |
| 点击后没有反应 | 确认环节没完成 | 刷新页面重新走一遍，见 [把一版草稿上线](../ship/release.md) |

## 确认上线成功了

```bash
skmr version list <地址> --status live
```

## 排查上线问题时要注意的

- **确认之前别再改这份草稿。** 页面打开时取的是那一刻的数据，不会自动刷新——你看到的可能已经不是最新的。
- **上线后内容不能改**，但线上指哪一版可以回滚、某一版可以下架。别把它当成「不可逆」——真出问题有退路，见 [把一版草稿上线](../ship/release.md)。
