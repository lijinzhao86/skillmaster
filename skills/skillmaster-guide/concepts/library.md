# 我的库影响什么

> 列表和搜索**默认只看这里面**。搜不到一个明明存在的公开 skill，多半是它还没进你的库。

## 库里有什么

- 你自己建的，以及别人共享给你、且你已在通知里接受的。
- 你从公开库收进来的：`skmr skill join <地址> --yes`。

## 收进来和移出去

```bash
skmr skill join <地址> --yes    # 收进库
skmr skill leave <地址> --yes   # 移出库
```

移出之后再收回来，**你之前贴的标签还在**，不用重贴。

- **完成信号**：`skmr skills list --source joined` 里能看到它；移出后看不到。

## 收进库不等于拥有

地址还是别人的——能不能改、能不能上线，看对方给了你哪一档，见 [共享给某个人](../ship/share.md)。

## 什么时候会用到

- 搜不到别人推荐给你的公开 skill → 先 `join`；共享给你的、还没接受的，先去通知里接受。
- 库里太乱、搜索结果被淹没 → `leave` 掉不用的。它们还在公开库里，随时能再收回来。
