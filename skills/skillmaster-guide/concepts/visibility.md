# 公开还是私有：谁能看见你的 skill

> 三档：**私有**、**公开 · 调用**、**公开 · 浏览**。选哪一档，实际是在回答：**你希望别人只拿来用，还是也能看到内容、甚至复制走。**

## 三档各给了什么

| 档 | 能被搜到 | 别人能做什么 |
|---|---|---|
| 私有 | 不能 | 只有你和协作者能访问，其他访问者无法得知它的存在 |
| 公开 · 调用 | 能 | 能调用；**知道确切路径就能读那个文件**，但没有文件清单，也不能浏览或搜索它的文件 |
| 公开 · 浏览 | 能 | 能调用、能看全部文件、能下载，**这个 skill 也能被复制** |

无论哪一档，skill 的「信息」页都能看到当前版本。

**能被搜到**要同时满足三件事：公开、有上线版本、没有下线。

## 怎么选可见性档位

- **想让人照着用、不想被抄走** → 公开 · 调用。
- **想被当成范例、想让人学** → 公开 · 浏览。注意：**已经发生的下载和复制收不回来。**
- **团队内部用** → 私有，再用 [共享](../ship/share.md) 按人发权限。

## 谁能改

需要「管理」这一档，**所有者永远可以**。`skmr skill visibility <地址>` 只打开设置页的「常规」，改动在网页上完成。

## 注意：公开档位与共享档位名字像，但不是一回事

这里的「调用 / 浏览」说的是**公开范围**；[共享](../ship/share.md) 里的「调用 / 浏览 / 写入 / 维护 / 管理」说的是**你给某一个具体的人多少权限**。两套名字长得像，不要混。

## 对可见性的常见误解

- **「公开就是谁都能改」**——不是。公开只决定能不能看见和使用。
- **「私有等于删除」**——不是。私有只是别人看不见。
