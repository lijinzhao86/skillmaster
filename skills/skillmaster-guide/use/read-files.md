# 读一个 skill 里的文件

> 两种用法完全不同：**读**（`read`）只取内容，读完这个 skill 并不生效；**加载**（`invoke`）才让它生效，并记住这次用的是哪一版。

## 先判断：读还是加载

| 你想 | 用什么 |
|---|---|
| 看看里面有什么、某个文件写了啥 | `read` / `ls` / `grep` |
| 照它说的做 | `invoke` |

## 四条最常用的命令

| 我想 | 命令 |
|---|---|
| 看目录里有什么 | `skmr skill ls <地址> [目录]`，加 `-R` 递归 |
| 加载正文、记住这一版 | `skmr skill invoke <地址>` |
| 读一个文件 | `skmr skill read <地址> <相对路径>` |
| 原样取整个文件 | `skmr skill cat <地址> <路径>` |
| 找某个词在哪 | `skmr skill grep <地址> <词>` |

其余查看命令（`head` / `tail` / `stat` / `wc` / `show` / `tags`）见 `skmr skill --help`。

- **完成信号**：`ls` 列出路径；`read` 打印带行号的内容与版本页脚；`grep` 一行一个命中；`invoke` 输出开头带地址与版本。

## 用的是哪一版

- **读取类命令**（`read` / `cat` / `ls` / `grep` 等）：你 `invoke` 过，就用**那次定下的**那一版；没 `invoke` 过、且有线上版本时按当前线上取。没有线上版本时的回落范围见下。
- **`invoke` 自己**总按当前线上解析，再用那一版重新钉住——加载就是重新选版本。
- **读 `SKILL.md` 是例外**：它等于加载，裸地址必须先 `invoke` 过，否则写 `@<版本>`。

要指定已发布版本，就写 `@<版本>`；草稿写 `@<版本码>`。

## 看有哪些版本：作者和读者用不同的命令

| 你是 | 用什么 |
|---|---|
| 只是使用者 | `skmr skill versions <地址>`——能调用哪些版本 |
| 作者或有「浏览」及以上 | `skmr version list <地址>`——每个版本的状态与时间 |

## 没有上线版本时会怎样

- **`read` 不回落**：它只认地址里写的版本，或上次 `invoke` 钉住的版本；有「写入」也一样。读草稿要写 `@<版本码>`，或先 `invoke`。
- **会回落的命令**（`invoke` / `cat` 与 `ls` / `find` / `stat` / `wc` / `grep` / `check`）：有「写入」及以上的人读到最近可见的那一版（通常是草稿），并注明用的是哪一版；只有「浏览」的人得到「这个 skill 还没有上线版本」；只有「调用」的人得到普通的「找不到」。

## 读文件时要注意的

- **`read` 的输出带行号**，直接写回文件会把行号带进去；要原始内容用 `--raw`，整份取用 `cat`。
- **`invoke` 只加载正文，不接文件路径。** 想读子文件用 `read`，路径从正文里抄。
