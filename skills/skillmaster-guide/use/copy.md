# 把别人的 skill 复制成我的

> 复制会生成一个**你自己的私有 skill**和一份草稿，内容取自对方某一版。它和源不关联：对方以后改了什么，不会同步过来。

## 先判断该复制还是入库

| 你要 | 用 |
|---|---|
| 只是用、不打算改 | `skmr skill join <地址> --yes` 收进库 |
| 要改内容、要发自己的版本 | `skmr skill copy` |

复制需要「浏览」及以上——「公开 · 调用」档没有文件清单，复制不了。**不能复制自己的 skill**；改自己的用 `draft create` / `edit`。

## 复制

```bash
skmr skill copy <地址> --name <新名字>
skmr skill copy <地址>@1.2.2 --name <新名字>
```

- 默认取线上版本；`@<版本>` 可以钉一个**已发布**的历史版本。草稿、已丢弃、已下架不能复制。
- 新名字必填，重名直接拒绝，不自动加后缀。
- **完成信号**：打印新地址与草稿版本码。

## 复制之后

1. 改内容：`skmr skill edit` / `write`，见 [改一个已有的 skill](../author/edit.md)。
2. 改 `SKILL.md` 里的名字，让它与新地址一致。
3. 上线，见 [把一版草稿上线](../ship/release.md)。

## 复制时要注意的

- **新 skill 是私有的**，复制不等于公开。
- **草稿阶段看不到「复制自」这条来源信息**（只能在控制台看）；上线后 `skmr skill show` 才会打印它。
- **源已下线时不能复制**，等作者恢复。

## 复制出错怎么办

| 现象 | 下一步 |
|---|---|
| 不到「浏览」档 | 请所有者共享更高档位，或直接问作者要 |
| 这是你自己的 skill | 复制只用于别人的；改自己的用 `draft create` / `edit` |
| 新名字已被占用 | 换一个 `--name` |
| 源的 `SKILL.md` 不能安全改名 | 用原名复制，再在编辑器里改 |
