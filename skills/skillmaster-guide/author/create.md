# 从零建一个 skill

> 建这一步本身不会出错——真正决定成败的是建之前定的**名字**和**描述**。完整的五步流程见 [第一次：从建到上线](../start/first-skill.md)，这一篇只讲怎么把这两样定对。

## 名字：地址的第二段

- 用别人会怎么称呼它，不要用内部代号。
- **不能含空格**，也不能有 `/` `\` `@` `%` `;`，不能是 `.` 或 `..`，最多 64 个字符。
- **建出来就改不了**，而且它会写进 `SKILL.md` 的 frontmatter——两边必须一字不差，否则会被拒。

## description：别人要不要用你，几乎只看这一句

写「做什么 + 什么时候用」：

> 处理 PDF：合并、拆分、提取文字。需要读或改 PDF 时使用。

不要写「一个强大的工具」——这类词对「什么时候用」没有任何信息。怎么打磨见 [描述、标签与分类](describe.md)。

## 建的命令

```bash
skmr skill create pdf-tools --description "处理 PDF 的工具：合并、拆分、提取文字。"
```

- **完成信号**：打印出地址和版本码，形如 `已新建 lijinzhao/pdf-tools@0NW9P6PP（版本名称：第一版）。`

网页上：「我的 skill」→「新建 skill」。

## 建完之后

草稿里只有一个占位的 `SKILL.md`。接下来写内容、检查、上线，照 [第一次：从建到上线](../start/first-skill.md) 走。

以后发新版**不是再 `create`**，是从线上开一份新草稿，见 [开一份新草稿](draft-create.md)。

## 想给 skill 改名

名字是地址的第二段，**建出来就改不了**，也没有「改名」命令；`skmr skill copy` 只复制别人的 skill，不给自己改名。要换名字只能新建一个 skill，再把文件传过去；旧的那份可以下线或删除，见 [下线、删除与恢复](../ship/delete.md)。

## 建 skill 出错怎么办

- **这个名字已被占用**：换一个名字。删除会立即释放名字，可以马上用同一个名字新建。
- 其余见 [上传不上去](../trouble/upload.md)。
