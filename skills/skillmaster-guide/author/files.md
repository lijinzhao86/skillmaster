# 草稿里的文件：移动、复制、删除、取到本地

> 移动、复制、删除作用在**某一份草稿**上，要带 `@<版本码>`；取到本地（`get`）可以针对任意版本。取下来的改动不会自己同步回去。

## 先判断对文件做什么

| 你要 | 命令 |
|---|---|
| 移动或改名 | `skmr skill mv <地址>@<版本码> <原路径> <新路径>` |
| 复制 | `skmr skill cp <地址>@<版本码> <原路径> <新路径>` |
| 删除 | `skmr skill rm <地址>@<版本码> <路径>` |
| 按名字找文件 | `skmr skill find <地址> <模式>`，加 `-i` 忽略大小写 |
| 取一个文件到本地 | `skmr skill get <地址>@<版本> <路径> -o <本地路径>` |
| 整版取成一个目录 | `skmr skill get <地址>@<版本> --all --into <空目录>` |

- **完成信号**：每条命令回一行结果；`get` 会打印落点与 sha256。

## 取到本地：单文件与整版

- **单文件**：`skmr skill get <地址>@<版本> <路径> -o <本地路径>`。
- **整版**：`skmr skill get <地址>@<版本> --all --into <空目录>`，一次性快照，连同 `.skillmaster/metadata.json`。

**整版会把包读进内存，上限约 17 MiB。** 更大的版本用单文件形态逐个取。

## 移动与取文件时要注意的

- **取下来改完再 `submit` 会被拒绝，或另开一份草稿**，和你手上那份对不上。要改这一版，用 `write` / `edit`，见 [改一个 skill](edit.md)。
- **`cp` 不能是第一次改动**：先有草稿，再复制。
- **本地取下来的文件不会自动同步**：先 `skmr skill read <地址>@<版本码> <路径>` 完整读一次，改完文本用 `skmr skill write <地址>@<版本码> <路径> --overwrite < 文件`；二进制用 `--from --overwrite`，见 [传二进制文件](media.md)。

## 文件操作出错怎么办

- **找不到草稿或路径**：`skmr version list <地址> --status draft` 核对版本码，`skmr skill ls <地址>@<版本码>` 核对路径。
- 其余见 [上传不上去](../trouble/upload.md)。
