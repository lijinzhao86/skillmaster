# 开一份新草稿

> 新建草稿是一个**独立动作**：`skmr draft create` 从线上版本（或你指定的一版）整版复制出一份草稿，内容不变，然后你在上面改。它和「新建 skill」不是一件事。

## 先看有没有开着的草稿

```bash
skmr version list <地址> --status draft
```

- 有：接着那份改，见 [改一个已有的 skill](edit.md)。
- 没有：用下面的命令开一份。

## 开草稿

```bash
skmr draft create <地址> --name "这一版的名字"
skmr draft create <地址> --from 1.2.0 --name "从旧版起稿"
```

- 默认从线上版本起稿；`--from` 可以指定版本名或版本码。
- **完成信号**：打印版本码，与一条可直接复制的写命令。

## 已经有一份草稿时

命令会拒绝，并列出你在这条 skill 下的草稿。**确实要另开一份时，先问用户**——多开的草稿会互相遮蔽，上线时也容易发错。

## 开完之后

照打印出来的那条 `skmr skill write` 写第一个文件；之后用 `edit` / `write` 接着改。

## 开草稿时要注意的

- **名称是版本列表里看到的那一行**，写「改一下」等于没写。
- **草稿不上线，别人看不到**，见 [草稿和线上版本的区别](../concepts/versions-and-drafts.md)。

## 开草稿出错怎么办

| 现象 | 下一步 |
|---|---|
| 你没有写权限 | 请所有者给你「写入」及以上 |
| 底稿找不到 | 核对地址与 `--from` |
