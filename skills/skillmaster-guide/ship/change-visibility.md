# 改一个 skill 的可见性

> 决定的是「别人能不能**看见**它」，不是「别人能不能**改**它」。改档需要「管理」，而且改动要在网页上完成。

## 先想清楚改成哪一档

三档各让出什么、怎么选、为什么「公开 · 浏览」收不回来，都在 [公开还是私有](../concepts/visibility.md)——那里是权威，这里只讲怎么改。

## 改可见性的命令

```bash
skmr skill visibility <地址>
```

`skmr skill visibility` 先确认你有「管理」及以上的档位，然后**打开**设置页的「常规」；命令本身不改任何东西。

网页上：skill 详情 →「设置」→「常规」。

- **完成信号**：刷新页面，三档里选中的变成你刚选的那个。

## 改可见性时要注意的

- **公开之后能被搜到，名字、描述、标签从此都是公开信息。** 改之前想一遍。
- **改可见性和「谁能改」是两件事。** 公开只决定能不能看见；能不能改看的是 [共享](share.md) 里给的档位。

## 改可见性出错怎么办

提示需要「管理」，说明你手上的档位不够——把地址给有这个档位的人，所有者一定有。
