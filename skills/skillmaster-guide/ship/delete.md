# 下线、删除与恢复

> 三件事不一样：**下线**是临时停服，随时能恢复；**删除**是让它对所有访问者消失；**恢复**把删掉的找回来。最要紧的一点：**删除会立即释放名字**，数据仍留一份可以恢复。

## 先判断该下线还是删除

| 你想 | 用 |
|---|---|
| 暂时别让人用，但什么都别丢 | 下线 |
| 彻底不要了 | 删除 |
| 删错了 | 恢复 |

## 下线与恢复服务

```bash
skmr skill offline <地址>   # 打开网页确认
skmr skill online  <地址>   # 打开网页确认
```

下线之后，按地址调用的人都会得到「服务已下线」，它也不再出现在搜索与公开列表里；**版本状态与当前版本都不变**，恢复后不需要重新上线。

- **公开、有线上版本、且有人入库**的 skill 先进入 **「下线中」30 天**：期间照常可调用、每次带提醒，但**不接受新入库**；入库者与授权者收到「复制到我的库」的通知。满 30 天转「已下线」，这时才能删除。**取消下线**用 `skmr skill online <地址>`（下线中时 `skmr skill offline` 会拒绝并指向它）。
- **下线完成信号**：`skmr skills list --show offline` 里能看到它；下线中用 `--show pending`。
- **恢复完成信号**：`skmr skills list --show live` 里能看到它。

## 删除

```bash
skmr skill delete <地址>
```

- 命令**先说明后果，不删除**；确认之后按它给出的完整命令重跑。
- **上线过的 skill 不能由凭据删**：它会打印设置页地址并以失败退出，由人在网页上确认。
- 删除后地址立即失效；**名字立即释放**，可以用同一个名字新建。数据仍保留在「已删除」里。`skmr skill restore <地址>` 恢复该地址下**最近删除的一条**；删过多次同名 skill 时，到控制台「已删除」列表按条目恢复。恢复时原名已被占用，会改名为 `原名-restored-<id>`。

## 恢复

```bash
skmr skill restore <地址>
```

- **完成信号**：命令报告已恢复。

## 下线与删除时要注意的

- **拿不准就下线，不要删除。** 下线可逆；删除要恢复，而且期间别人手里的地址早就失效了。
- **删除前先查谁在用。** 私有 skill 用 `skmr usage <地址> --users` 列协作者，授权者用 `skmr skill shares <地址>` 查；公开 skill 的 `--users` 只给聚合、不列名字，入库者靠「下线中」的通知触达。公开且有入库者的 skill 要先走完 30 天下线中才能删除。

## 删除出错怎么办

- **提示你不是所有者**：删除与恢复只有所有者能做。
- **看不到这个 skill**：用 `skmr skills list --show deleted` 核对。
