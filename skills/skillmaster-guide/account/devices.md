# 登录设备与 API key

> 控制台两个地方管凭据：**登录设备**管 `skmr login` 换来的；**API key** 管你签发的 `skm_` 密钥。想让某台机器失效，来这里。

## 什么时候用哪个

| 你想 | 去哪 |
|---|---|
| 让某台电脑上的命令行失效 | 登录设备 |
| 给 CI / 服务器发凭据 | API key |
| 查某把凭据还在不在用 | 两处都要看 |

## 登录设备

https://console.skillmasterai.com/account/sessions

每条记录是**一次登录**——可能是浏览器会话，也可能是 `skmr login` 换来的命令行登录，两类都在这一页。显示的是：哪台设备或哪个来源地址、什么时候登录、最近一次活动。结束一条，对应的那次登录就失效了。

命令行的记录里，来源地址显示的是**批准它登录的那个控制台访问者**的地址，不是那台命令行的机器地址。

## API key

https://console.skillmasterai.com/account/keys

在这里创建和撤销。创建后放到目标机器的 `SKILLMASTER_API_KEY` 里。

## 管理设备与密钥时要注意的

- **两处的失效方式不同**：登录设备是「结束」某次登录；API key 是「撤销」某把 key。查漏的时候两边都要看。
- **`skmr logout` 不会删这里的任何记录**，它只清本机。
