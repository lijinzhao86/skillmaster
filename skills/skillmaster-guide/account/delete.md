# 注销账号

> 注销只能在控制台做，**立即生效、不能撤销**。账号马上不能登录，个人空间里的 skill 马上不可用；30 天后这些内容与账号资料被删除或去标识化。命令行没有注销命令，只能在控制台做。

## 先看注销会带走什么

| 对象 | 注销后 |
|---|---|
| 账号 | 立即不能登录；所有会话结束 |
| 你个人空间里的 skill | 立即不可用；30 天后随账号清理 |
| 你在别人 skill 里的贡献 | 保留，作者显示为「已注销账号」 |
| 你分享给别人的访问 | 失效，并通知对方 |
| 行为日志 | 按隐私政策保留，不随注销删除 |
| 同一手机号与用户名 | 30 天内不能重新注册 |

**要留内容，先导出**：先 `skmr skills list` 看要留哪些，再对每个跑一次 `skmr skill get <地址>@<版本> --all --into <空目录>`，每次换一个空目录；草稿写 `@<版本码>`。见 [草稿里的文件](../author/files.md)。

## 注销

1. 打开 https://console.skillmasterai.com/account
2. 到页底「危险操作」→「注销账号」。
3. 输入**用户名与密码**确认。

- **完成信号**：回到登录页，显示「账号已注销。」；再用原来的凭据跑 `skmr auth status` 会失败。

## 注销前要做的

- **导出还想留的内容**：个人空间里的 skill 会随账号清理。
- **告诉被共享的人**：他们的访问会失效，并收到通知。
- **检查在用这个账号的 CI**：API key 随账号一起失效。

## 注销出错怎么办

| 现象 | 下一步 |
|---|---|
| 提示用户名或密码不对 | 核对后重试；密码忘了先走 [找回密码](register.md) |
| 30 天内想用同一手机号或用户名注册 | 换一个，或等满 30 天 |
