# 我还没有能用的账号

> 账号要自己注册：**用户名 + 手机号 + 密码 + 短信验证码**。用户名一旦定了就改不了，它会成为你发布的每个 skill 地址的第一段。

## 注册

打开 https://console.skillmasterai.com/register

四样东西：

| 填什么 | 注意 |
|---|---|
| 用户名 | **永久**，会成为地址的第一段（`用户名/名称`）。不要用真实姓名或手机号 |
| 手机号 | 收验证码用 |
| 密码 | |
| 短信验证码 | 发到你填的手机号 |

- **完成信号**：注册成功后直接进控制台，不需要再登录一次。

## 忘记密码

打开 https://console.skillmasterai.com/reset

手机号 + 短信验证码 + 新密码。

- **完成信号**：用新密码能登录。

## 改密码

控制台没有「改密码」的入口——改密码就是**走一次找回密码**：手机号 + 验证码 + 新密码。它会结束所有已经登录的会话，各处的命令行要重新登录。

## 注册与改密码时要注意的

- **用户名同时是命名空间。** 所有 skill 地址都以它开头，改不了——只能换账号。所以起名时想一遍：别人会不会照着这个地址找你。
- **网页注册完，命令行还没登录。** 两件事，见 [登录](sign-in.md)。

## 注册出错怎么办

- **提示手机号已注册**：这个号码已经有账号。去 [登录](sign-in.md)，或者用上面的「忘记密码」重设。
- **收不到验证码**：等一会儿再重发；仍然收不到，先核对手机号有没有填错。
