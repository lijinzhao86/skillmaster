# 第 3 步 · 正式上线

**这一步做什么**：让用户在网页上把草稿正式上线——这一步 Agent 不做，也不能代劳。
**什么时候做**：`import/02-upload.md` 至少传成一个之后。
**做完的标志**：这次传上去的那几个都不在待上线队列里了，抽一条能取到正文，并且已经给了他一个能照着试的例子。

## 步骤

1. **对他说**：

   全部传成了就说「传完了」；只传上去一部分就说「传上去 N 个」。后面照说：

   > 还差一步在网页上：把要用的技能勾上，点「上线所选」。链接我发你，弄好了告诉我，我再跟你确认一下。

2. **把链接给他**（或直接打开）：<https://console.skillmasterai.com/publish>。页面上是「待上线」清单，把这次传的要用的技能勾上，点「上线所选」，确认单再点「确认上线」。

   **不要替他点，也不要假定已经上线。**

   **他回来后，先用卡片确认**（两个选项；问句带上「该看到什么」）：

   > 刚才勾的那几条，现在从「待上线」清单里消失了吗？

   `消失了，都上线了（推荐）` / `还没消失`

   - 他点「消失」：往下核对。
   - 他点「还没消失」：先问一句「你现在页面上看到的是什么？」，再按第 3 步核对；**不要重复上线**。

3. **他回来后只读核对**：

   ```bash
   skmr skills pending
   ```

   **这是这个账号下等着上线的草稿清单，不是这一批；超过 500 个它会说自己没列全。** 只认这次传上去的那几个名字还在不在里面；别的 skill 的旧草稿不算。队列空的时候它说没有你能上线的草稿（它只列你有权上线的）——那也是清空。

4. **抽一条验一下**：

   ```bash
   skmr skills list --verbose
   skmr skill invoke <地址>@<版本>
   ```

   版本用上面 `--verbose` 里「版本：」那一行。**地址要带 `@版本`**：不带就取线上当前那一版；带上才是你刚核对过的那一版。另外注意 `invoke` 会记住这一版，给后面的 `skill read` 用，不是纯只读。

   挑这次传上去的一条，能取到正文，才算真的上线了。

5. **告诉他全好了，再给一个能照着试的例子**：

   > 上线完了，这次传上来的 N 个技能现在都能用了。
   >
   > 试一下：跟你的 Agent 说「用 SkillMaster 找一下<某个技能的名字>」——它就会来 SkillMaster 找。

   例子里挑他刚传上来的、最像他平时会用的那一个，用**名字**，不要给地址或编号。

## 出问题怎么办

| 情况 | 对他说 | 然后 |
|---|---|---|
| 这次传的都不在队列里 | — | 继续本文件第 4、5 步 |
| 这次传的还有在队列里 | 报出剩下哪几条，并说明它们还没正式上线，所以现在还用不了 | 停在这里，回 `SKILL.md` 的「收尾」 |
| 他不想现在去网页上线 | 没关系，草稿先存着；想上线的时候随时在网页上点 | 回 `SKILL.md` 的「收尾」，这一步算没做完 |
| 网页让你登录 | 网页和命令行是两套登录：你命令行登过了，浏览器里还得登一次，用同一个账号。登完会自动回到这一页。 | 让他自己登；**别让他把密码发给你** |
| 页面打不开 | 我把链接发你，你在自己的浏览器里打开就行。 | 把 <https://console.skillmasterai.com/publish> 再贴一次 |
| 网络读不到 | 说「暂时读不到」 | 重试一次；还读不到就停在这里，回 `SKILL.md` 的「收尾」 |
| 抽的那条取不到正文 | 这条现在还取不到，可能是没上线完 | 停在这里，不要说「都好了」，回 `SKILL.md` 的「收尾」 |

## 下一步

这次传的都上线了、抽的那条取得到正文、试用的例子也给过了，才读 `import/04-cleanup.md`：备份、再问他要不要清掉电脑上原来那份。
