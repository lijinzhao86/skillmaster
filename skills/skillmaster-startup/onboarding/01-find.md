# 第一块 · 第 1 步 · 找：公开库里有什么

**这一步做什么**：让他看到公开库里真有现成的做法，并挑中一条。
**什么时候做**：从 `SKILL.md` 进入第 1 步时。
**做完的标志**：他挑中一条公开 skill，你手上有了它的地址。

## 步骤

1. **对他说**（用选项卡，不要让他打字）：

   > SkillMaster 上有一个公开库，里面是别人做好、谁都能搜到的技能。先看看里面有什么——你平时最想让 AI 帮你做什么？

   选项卡（第一个是推荐；这三个例子**实测都能在公开库搜到**，换例子前先搜一遍）：

   `做 PPT（推荐）` / `翻译一篇文章` / `画一张流程图` / `我自己说`

   - 他点了一个例子：按那个例子搜公开库。
   - 他点「我自己说」：再问一句「那你说，想让它帮你做什么？」，按他的原话搜。

2. **按他的原话搜公开库**，一次一句，不要堆关键词：

   ```bash
   skmr skills search "<他的原话>" --scope public --limit 5
   ```

   - 搜到 1–5 条：把最贴近他需求的那条放第一个，用选项卡让他挑——`<最贴近的那条>（推荐）` / `<第二条>` / `<第三条>` / `这些都不对`。**卡片最多 4 个选项**；不够 3 条就少放几个，不要凑。卡片上用一句人话写它做什么，不要只写英文地址；地址留在正文里。
   - 卡片的问句带上他刚才说的那句话，例如他说「画一张流程图」，就问「你想画流程图，这几条最贴近，挑哪条？」——原话照引，不要改写。
   - 他点「这些都不对」：换一个说法再搜一次（仍用这 4 个位置）；第二次还是不对，走下面的兜底。
   - **搜不到**：换一个说法再搜一次；仍然没有，就用「做 PPT」兜底：

     > 我们先拿「做 PPT」当例子——公开库里有一条现成的。

     ```bash
     skmr skills search "做一份 PPT" --scope public --limit 5
     ```

     当前会搜到 `skillmaster/baoyu-slide-deck`（公开 · 浏览）。让他挑一条。

3. **他挑中后**，记下地址，进入下一步。

## 出问题怎么办

| 情况 | 对他说 | 然后 |
|---|---|---|
| `skmr` 报错（没登录 / 连不上） | 技能库暂时查不了。 | 按报错里的下一步处理；别假装搜过 |
| 搜到的都不合适 | 这几条都不合适？那我们换一个说法再找。 | 回到第 2 步，用他的新说法搜 |
| 他不想挑 | 那我们先拿「做 PPT」当例子。 | 用兜底那条 |
| 兜底也搜不到 | 公开库里暂时没有合适的，我们先停在这里。 | 如实说，不空手结束；按 `SKILL.md` 的「收尾」走 |
