## 第二次：控制台（2026-10-09）

首页交付之后，用户说：

> 接下来我们做控制台的页面。先帮我把控制台页面的框架搭建好

动手前先定了两个岔口，用户的选择分别是：

| 岔口 | 用户选择 |
|---|---|
| 这一版落在哪一份代码上 | **`design/` 演示件**（不碰 `skillmaster-web/` 的产品代码） |
| 「框架」指到哪一层 | **外壳 + 页面骨架**（一级导航 / 品牌区 / 账号区，加页面级的可复用容器） |
| 视觉方向怎么定 | **沿首页原研哉「白」** |

### 为什么这一次不再过三方向门

按 huashu-design 的「唯一豁免」第 2 条——**已选定方向后的迭代**：

1. 方向已由用户在上一轮选定（原研哉「白」），控制台是同一项目、同一品牌下的**加屏**，不是另一个设计问题；
2. 它还有**既有的设计上下文**：真实产品的控制台已经存在（`skillmaster-web/` 的左侧导航 + 卡片 + 表格 + 状态胶囊），信息架构是给定的，不是从零开始；
3. 用户本次要的是**结构**（「框架搭建好」），不是重新选方向。

因此本次直接进入深化，没有产出新的三版初稿。

### 这一版相对首页做的唯一方向性翻译

首页的「白」是一屏没有容器的版面；控制台是密集功能面，而真实产品用的是「灰底 + 白卡 + 阴影」。**这一版不用盒子**——用栏宽和发丝线分区，全页零卡片底、零阴影，页面上唯一有底色的东西是「等你上线」那块面板。

这不是换了一个方向，是同一个方向落到密集界面上必然要做的翻译。依据：`demos/dir3-hara-console.html` 文件开头那段注释；交付件 `skillmaster-控制台演示.html`；十个状态的截图在 `shots/console/`。

### 为什么这一次同样不过三方向门

## 第四次：控制台换到了产品那一档（2026-10-15）

访问凭据那一页做完之后，用户看了一张参照产品的凭据页截图，说：

> 为什么我们的UI设计这么丑呢？能否直接用gitlab的UI设计呢 …… 直接复用这里面的代码

### 为什么这次不是「再过一次三方向门」，而是「回去照自己的规范」

动手前先去做了一件事：**核实「复用它的代码」到底可行不可行**，而不是先答应。三条结论，两条走不通：

| 做法 | 结论 |
|---|---|
| 把 `@gitlab/ui` 装进演示件 | **不行**——Vue 2.7 组件（peer 依赖 `vue: ^2.7.16`）+ Tailwind 3，而演示件是自包含单文件 HTML、零构建 |
| 装进真实产品 | **不行**——我们是 Vue 3 + Vite（[ADR 0015](../../docs/decisions/0015-web-frontend-stack.md)），那是降级到 Vue 2 重写 |
| 拿它的**设计令牌**与排版习惯 | **行**，但它不是最该看的那一份 |

**因为最该看的那一份是我们自己的。** `brand-spec.md` 开头写着它是「**本产品一切视觉事实的权威位置**」，而它给的正是产品那一档：**页面底 `#f6f8fa`（灰）+ 卡片面 `#ffffff`（白）**、悬停面、两级极轻的阴影、圆角 6/10、以及 1.35/1.25/1rem 的三级标题——气质一栏写的是「克制的企业级开发者工具，参考 GitHub / Linear 的密度与层级」。

**而控制台一直在用营销页那份暖白 `#fdfcfa` 当底，并且在代码注释里明写着「The console itself never uses it」**（指 `--surface`）。也就是说：**不是缺品味，是控制台单方面退出了本产品的视觉规范**，凭的是首页那个方向的授权。

那条授权用错了地方。首页的「白」在营销页上是对的；**搬到密集功能面上，它就变成「没有面、没有分组」**——而发丝线能分开，不能建立层级。

### 用户的选择

> 只给控制台换一套（推荐）

**一个品牌两档密度**：首页那份「白」不动，控制台回到 `brand-spec.md` 的产品那一档。主色仍是我们的蓝，标记、字体栈、胶囊语义全部不变。

### 落地了什么

- **内容列成了白面**（`.content{background:var(--surface)}`），侧栏留在灰底上——**这是整件事最大的一处**
- **四格统计成了四个盒子**（原先以「这一版不画面」为由拒绝借参照产品的卡片，**那个理由随着方向一起消失了**）
- **凭据列表也成了盒子**（壳 + 白底两层）——第三次那一段写的是「用行 + 发丝线，不为它新开一个表格块」，它依据的是同一个「不画面」，所以一起失效；列表的**形状**没变，变的只是它现在有一块面
- **表头行有了底色**，行有了悬停
- **分组标题从「灰色字距标签」改成「深色标题」**——层级靠墨色与字重，不靠把它调暗
- `h1` 用规范里的 1.35rem/700；卡片用规范里的圆角 10 与两级阴影中的浅那一级

### 连带的诚实交代

`console-states.mjs` 里有一条断言原文是「**skill 页：表头不靠底色区分，靠那条发丝线**」——**它钉的正是被推翻的那条规矩**。它变红是对的，所以**断言跟着翻**（从「不靠底色」改成「靠底色」），而不是把设计退回去。README 里那两句「表头行没有底色」「页面上没有任何一块填色的区域」也一并标了已改——**一处事实只留一处说法**。
