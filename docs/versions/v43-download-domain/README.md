# v43-download-domain · 下载入口换回自己的域名，首页标出备案号

> **最后更新**：2026-11-04
> **状态**：进行中（设计、技术设计、实现与本地验证已完成；待视觉验收与 PR）
> **含收费**：否

## 目标

把用户可见的 CLI 下载链接从 OSS 桶直连换成 `https://dl.skillmasterai.com`，并在首页页脚标出 ICP 备案号 `粤ICP备2026172880号`。细节见 [`prd.md`](prd.md)。

## 验收标准

八条验收（A1–A8），摘要其中三条：用户入口不再出现桶地址；TLS 1.2 客户端能从 `dl.` 完成安装；首页页脚显示备案号并链接到工信部备案系统。完整验收见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：A1（入口全部换域名）与 A5（页脚备案号）不满足就不算交付。

## 这一版明确不做什么

- 不改工作流的 OSS 上传端点与从桶回读校验 —— 那是控制面与规避 runner→ECS TLS 的刻意选择，不是用户链接
- 不下线旧桶地址 —— 已装好的 CLI 还要从桶自查更新
- 不给控制台加备案号 —— 本次只处理 `www` 首页；控制台要不要挂是另一个界面决定

## 与目标态的关系

[`target/`](../../target/) 描述的是**完整形态**。这一版不新增产品能力，只把发布入口从临时通道换回正式域名，并补上合规标记：

- 保留的部分：安装说明、CLI 包、自更新通道的内容与流程都不变，只换地址。
- 已经分叉的部分：无。
