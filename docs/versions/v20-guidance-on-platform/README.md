# v20-guidance-on-platform

> **状态**：进行中。P0：规则段已上线（`@1.0.1`），旅程改为可执行的命令（第一步 `skill submit`、第五步手动下线）在草稿 `@9MP5595A` 里待上线；P1 完成（CLI 已改为加载技能）；P2 完成到「本地验证通过、待部署」（服务端路由与 `gateway/` 已删，生产上的 404 要等部署后才成立）。

## 目标

把两段**引导内容**都放到平台上的官方技能 `skillmaster/startup` 里：一段是旅程正文，一段是用户要粘进系统提示词的规则。`skillmaster startup` 只做三件事——确保登录、报告当前位置、加载这个技能；改一句文案不必再发版 CLI 或服务端。细节见 [`prd.md`](prd.md)。

## 这一版明确不做什么

| 不做 | 原因 |
|---|---|
| 在 CLI 或服务端留一份规则 / 旅程的副本 | 两处存放必然漂移；规则只有一个权威位置（[ADR 0096](../../decisions/0096-guidance-lives-on-the-platform.md)） |
| 技能不可用时的内置兜底正文 | 兜底就是第二份会过期的文本；失败时如实报错并指路（prd 验收 7） |
| 新的控制台操作 | 技能的编辑与上线沿用既有控制台流程 |
| 改 `skills import` / `skills retire` 的行为 | 属于 [v17](../v17-cli-startup/README.md) 的范围 |

## 验收标准

见 [`prd.md`](prd.md) §验收与指标——7 条，覆盖「startup 的输出」「规则的唯一位置」「help 不再携带规则」「服务端路由退休」「失败时怎么报」。

## 与目标态的关系

`docs/target/` 描述的是「agent 不装 skill 副本、按需拉取」。这一版让**引导本身**也成为平台内容：引导的更新节奏跟内容走，不再跟二进制走。
