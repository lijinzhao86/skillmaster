## 目标

**本版最终交付的形态：装到用户电脑上的 skillmaster 只有一个 `SKILL.md`。** 它只负责「什么时候查、查完怎么答、最常用的命令」；分步的操作说明**改由**公开库的 SkillMaster 官方技能提供——**那个技能本版不创建也不发布**，用到时再去拿。细节见 [`prd.md`](prd.md)。

三条主线（按加入顺序）：

1. **源在仓库**：`skills/skillmaster/` 是本地包的源。`sop/` 2026-11-03 整目录删除，内容将迁往公开指南（本版不发布它）。
2. **SOP 修正**（2026-11-03 作废）：原本要修 `sop/*.md` 里漂移的指令——`--name`、本地目录与 `submit`、两步确认等；`sop/` 删除后这些条目一并取消，A8 / A9 / A11 / A12 随之取消。
3. **触发契约（2026-11-02）**：检索是默认动作；**触发判据与例外的权威在 `description`**（[ADR 0109](../../decisions/0109-the-rule-block-defaults-to-searching-first.md)），随 CLI 发布的常驻规则段只负责在加载之前催促调用（[ADR 0102](../../decisions/0102-the-rule-block-ships-with-the-cli.md)）；正文写成两条并列分支 + 四步调用流程。

**两条要如实记下的债**：目录名 `skill-source-sync` 早于第 3 条主线；本版最初的目标是「包从 8 变成 9」，被第 3 条主线取代成「包只剩 1 个」——那条 8→9 的记录只在本版历史里成立。

## 验收标准

二十条（A1–A20），摘要：源在仓库；**本地包只有 `SKILL.md` 一个文件**；frontmatter 的 `name: skillmaster` 仍在；仓库与包里都没有 `sop/`；文档检查通过；**安装文档、`site.yml`、打包脚本里没有残留的 8 / 9 文件计数**；线上字节与构建产物一致（部署时）；命令参数用 `--help` 查；分发包去掉内部 ADR / 历史 / API 细节 / 作者提示；`SKILL.md` 把调用流程写成四步（搜索 → 判断 → 规划 → 加载），并把**对 skill 的操作单列成并列分支、排在前面**；**描述写清五件事：任何任务先加载 / 六种该加载的情形 / 操作也强制 / 三种例外 / 拿不准按任务处理**；**禁区只覆盖「改」，不挡搜索、加载、读取**；**常驻规则段（`block.md`）只做催促：一句催促 + 三句反借口，不带判据、例外、回执与任何命令**。完整验收见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：A2、A6、A13、A14 不满足就不算交付——文件数错了，安装说明的「数够 1 个文件」会让每一次安装失败；残留的 8 / 9 会让安装说明与真实包对不上；A13 错了，分发包会带上内部 ADR 与作者提示；A14 错了，agent 拿到派发版却不知道四步怎么走。

- 不发布公开指南 — 分步说明迁往 `skillmaster/skillmaster-guide`，由技能主人在平台上另发，本版不创建也不发布它。
- ~~不采用全局的 `sop/03-edit-draft.md`~~ **已作废** — `sop/` 已整体删除。
- ~~不删除 `sop/07-files.md`~~ **已作废** — 同上。
- 不做 CLI 拦截 — 正文的 `invoke` / `read` 分工已写进 `SKILL.md`（见 A14）；拦截要先定提示还是拒绝、覆盖哪些命令，记在 [`TODO`](../../current/TODO.md)。
- 不改服务端、控制台、CLI 行为与设计稿 — 本版只改技能包、安装文档与 CI 闸。触发契约只做到「正文里的行为约定」；**让 `skmr` 记 search / invoke / outcome 事件、多 skill 的声明式串联、把「查完报一行」写进常驻规则段，都记在 [`TODO`](../../current/TODO.md) 第 9、10、11 条**。
- 不在 repo 验收里同步本机副本 — 本机副本是部署 / 安装产物。
- ~~在 `sop/03` 引入本地包 / `repo-first` 模式~~ **已作废** — `sop/` 已删除。
- 不把 `description` 改成能力描述 — 用户 2026-11-02 决定保留 always-load；本版只清内部文案。

## 与目标态的关系

[`target/`](../../target/) 描述完整形态。本版**改了交付形态**：装到本机的技能从 9 个文件变成 1 个，分步说明改由公开库提供。能力边界没有扩大——`skmr` 的命令面、权限、版本模型都不变；变的是「说明放在哪」与「agent 什么时候去拿」。与 `target/` 不分叉。

**这一条是有代价的**：公开库查不到、或用户没登录时，agent 只剩 `--help` 与现场报错。本版接受这个代价，兜底方案见 [`technical-design.md`](technical-design.md) §开放问题 Q5。
