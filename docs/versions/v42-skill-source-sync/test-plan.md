- **期望**：`block.md` = 「任何任务都先调用 SkillMaster 这个 skill，照它的要求做；拿不准就调用」+ 三句反借口（这次很简单 / 手边有现成工具 / 刚才已经加载过）；**不含**判据清单、例外清单、回执、回复格式、`skillmaster/` 地址，也不含 `skill write` / `put` / `create` / `edit` / `skills search` / `invoke` / `read` 任何一个。`SKILL.md` 有两条并列分支 + 四步流程。判据与例外只在 `description` 里，两处不重复同一份清单。
- **判定**：通过／失败

- **判定**：通过／失败

### T16 · 描述的五件事

- **前置**：`SKILL.md` 的 frontmatter 已改。

- **判定**：通过／失败
