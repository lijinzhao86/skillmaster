# v28-console-brand-links-home · 控制台的品牌点回营销站首页

> **最后更新**：2026-10-29
> **状态**：已完成（代码与文档同分支 `feat/console-brand-links-home`，文档与守卫用例未提交）；验收 6 待人工
> **含收费**：否

## 目标

控制台左上角「SkillMaster」从 `href="/"`（回控制台根，也就是「我的 skill」列表）改成**回营销站首页**——与控制台「退出登录」失败页那句「回到首页」同一个地址。细节见 [`prd.md`](prd.md)。

## 验收标准

点品牌落到 `https://www.skillmasterai.com/`（构建变量 `VITE_SITE_URL` 的原值，尾斜杠由 `siteUrl.ts` 补）；它和 `/logout` 读同一个值；「还没复制的密钥」那道守卫仍然拦住它。完整验收（6 条）见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：验收 1（点品牌回到营销站）、验收 4（守卫仍然拦住）——这两条不满足，这一版就没有交付。

## 这一版明确不做什么

- **不做「控制台首页」这一屏**——产品里从来没有它，出控制台就该是一个真实的出口。
- **不改成新窗口打开**——它是「回首页」，不是「去别处看看」；`/logout` 那条出口也是同一个 tab 走（理由见 [`prd.md`](prd.md) §范围）。
- **不动视觉**——标记、字号、字距、颜色、悬停态都不改。
- **不改演示件的运行行为**——演示件没有外部站点，它的 `?page=skills` 是替身（[`design/README.md`](../../../design/README.md) §控制台演示 › 顶栏的品牌回首页），这一版只补了一句说明。

## 记录的性质

**这一版不改「对外能验收的能力边界」**——它换的是一个链接的去向。按仓库的流程，界面改动先改设计稿、三份文档可以省；这三份是产品负责人要求补的记录，不是「这一版必须新开一个版本」。

## 与目标态的关系

[`target/`](../../target/) 这一版没有分叉：它补上了一个早就该存在的出口，不改任何边界。
