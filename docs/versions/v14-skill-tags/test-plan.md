## 用例

### T1 · 迁移、表归属与清库清单

- **前置**：干净测试库；服务端在 `V25`。
- **步骤**：跑 `V26`–`V28`；检查 `ModuleMap` 的 M12 表集合；跑 `TableOwnershipTest`；检查 `truncate-business-tables.sql`。
- **期望**：五张新表与 `skill.category_key` 存在；M12 集合与迁移表集合完全相等；清库清单包含四张**业务**表、**不包含 `skill_category`**（平台种子要留下）；重复迁移幂等（Flyway 不重跑）。
- **判定**：通过／失败。

### T2 · 约束、索引与词表种子

- **前置**：T1 通过。
- **步骤**：插入重复 `skill_public_tag`、重复 `(user_id, name_key)`、长度 25 的名字、非法 `state`、外键指向不存在的 skill / 定义；查询 `skill_category` 与索引；在已有我的标签的库上尝试新增一个撞名的公开分类、再尝试一个与词表任一词撞名的分类；查存量 skill 的分类。
- **期望**：唯一 / 外键 / CHECK 按 §数据模型拒绝；10 个分类按 `sort_order`；`ops` 为 `stopped`；`skill.category_key` 只有一列、可空；**迁移在撞名时拒绝**；**退役词名继续占用**；**存量 skill 全部是 `NULL` 分类，没有自动归类**。
- **判定**：通过／失败。

### T3 · 标签名规范化

- **前置**：无数据。
- **步骤**：对 `TagNames.normalize` 跑表驱动：全角 / 半角、大小写、首尾空白、连续空白、NFKC 等价值、24 / 25 个码点、空串。
- **期望**：key 与 PRD 的规范化规则一致；显示名保留作者写法；24 通过、25 拒绝；空串拒绝。
- **判定**：通过／失败。

### T4 · 可见性与 404 / 403

- **前置**：两个账号；一个 private、一个 public skill；grant 覆盖 `invoke`–`admin`。
- **步骤**：分别以所有者、被授权者、陌生人读详情与三组词；**不带会话**请求 `/web/library`、`/web/discover`、`/web/discover/recommended`、`/web/tags`。
- **期望**：不可见 → 404 `skill_not_found`；可见但无权写 → 403 `forbidden`；公开未加入 → 可读；所有者 / `admin` 可写分类与公开标签；**四个新 `/web` 路径不带会话一律 401**（它们必须在 `SecurityConfig` 的 `authenticated()` 里，不能落 `permitAll`）。
- **判定**：通过／失败。

### T5 · 公域可发现谓词

- **前置**：构造 public / private、有 / 无当前版本、在线 / 下线、已删除、带分类与公开标签的 skill。
- **步骤**：公域检索；`/web/discover`；分类计数；公开标签计数；推荐流。
- **期望**：只有「公开 ∧ 有当前版本 ∧ 未下线 ∧ 未删除」进入；其余不出现；计数只算这一集合。
- **判定**：通过／失败。

### T6 · 来源优先级

- **前置**：一个 skill 同时是我创建的、被共享的、被我加入的（用不同账号 / 关系组合构造）。
- **步骤**：读 `/api/v1/skills?scope=library` 与 `/web/library` 的 `source`；再对同一个已加入的公开 skill 读 `scope=public`，逐字段对照两张卡。
- **期望**：按 `created > shared > joined` 取一个显示；每种来源只出现一次；来源不因排序或筛选改变；**两个 scope 返回同一份字段集合与同一个 `source` / `state` 判定**（`LibraryListUseCase` 与检索共用 `SkillCard`，契约测试直接比字段名与值）。
- **判定**：通过／失败。

### T7 · 条目生效 / 休眠矩阵

- **前置**：我创建的、`write+` 共享、`browse` / `invoke` 共享、我加入的；每种各有在线、下线、无当前版本、软删除；另有一个「公开转私有但仍保留授权」的 skill。
- **步骤**：读库列表、我的标签、三组词与恢复后的状态；撤销对我的共享；把公开 skill 转私有（保留对我的授权）；分别再读一次。
- **期望**：创建与 `write+` 在线 / 下线仍生效；`browse` / `invoke` 与我加入的在下线、无当前版本、软删除时休眠；**撤销共享 → 共享来源消失；有加入引用且仍可读则条目留下、来源变我加入的、我的标签继续生效，否则条目离开库、标签休眠**；**公开转私有但仍有授权 → 条目留下、来源变共享给我的**；恢复可见或 `skill restore` 后回来；我的标签跟着睡眠 / 回来。
- **判定**：通过／失败。

### T8 · 加入边界矩阵

- **前置**：可见性 × 生命周期 × 当前版本 × 来源的矩阵夹具。
- **步骤**：逐个调用 `POST …/library`；重复调用；对创建 / 共享 / 不可见 / 下线 / 无版本逐个断言。
- **期望**：可加入的 204 且只新增一条引用（不复制版本、不改 digest）；重复加入 no-op；创建 / 共享 → 409 `SKILL_NOT_JOINABLE`；不可见 / 非公开 → 404；下线 / 无当前版本 → 409；未加入的公开 skill 仍可 `skill invoke`。
- **判定**：通过／失败。

### T9 · 移除、重加入与标签回来

- **前置**：已加入的 skill 上贴 1 个我的标签；作者另有一个新版本。
- **步骤**：`DELETE …/library`；读库与标签；再次加入；读库与标签；作者发新版后再读库内版本；在信息页触发一次移除看弹窗。
- **期望**：只删加入引用；条目离开库、我的标签休眠（读不到、计数不算）；作者内容与访问权不变；**作者发新版后库里的 skill 跟到新版**（引用语义）；重新加入后条目回来、标签原样回来；来源是创建、或共享但从未加入（没有引用）时移除 → 409 `LIBRARY_REFERENCE_MISSING`；**加入过、后来又被授权（显示来源变共享）时引用仍在，移除成功且来源仍是共享**；信息页移除是**普通弹窗（不染红）**，发现页书签回退不弹窗。
- **判定**：通过／失败。

### T10 · 库列表的 scope / show / source / 过滤

- **前置**：三账号 + 完整生命周期夹具。
- **步骤**：对 `scope=library` 跑 `--show` 五个值、`--source` 三个值、三类标签过滤、`q`、`--all`。
- **期望**：默认只列可消费的库；`draft` / `offline` / `deleted` / `all` 与 PRD 一致；`deleted` 只含我创建的并拒绝标签过滤；`source` 可重复取「或」；不同类取「且」、同类分类取「或」、我的 / 公开标签取「且」；公开未加入不出现。
- **判定**：通过／失败。

### T11 · 三种库空态的数据形状

- **前置**：空库；全部休眠；非空且无已删除；**只有我软删的 skill（0 个生效）**。
- **步骤**：读 `/web/library` 的响应；再在非空库上分别加 `q` 与 `show=all|deleted`。
- **期望**：响应带 `total_entries` / `effective_entries` / `filtered_total` 三个数；PRD 三种空态各有判据——`total_entries = 0`「库空」、`effective_entries = 0` 且 `total_entries > 0`「全在休眠」、`show=deleted` 且 `filtered_total = 0`「没有已删除」；**「只剩软删」也判「全在休眠」，同时「已删除」页签必须有行**（页签显隐只看 `total_entries`）；`filtered_total` 另用于筛选无匹配时的那一句（不占空态）；加 `q` / `show` 后 `total_entries` 与 `effective_entries` 不变、`filtered_total` 变。
- **判定**：通过／失败。

### T12 · 我的标签定义 CRUD 与上限

- **前置**：一个账号，已有 99 / 100 个定义。
- **步骤**：新建（含说明、空说明）、重名、撞分类名、改名、第 101 个；并发两个第 100 个请求。
- **期望**：新建 / 改名成功且 `used_in` 为 0；重名 / 撞分类 → 400 `invalid_request`（field `name`，issue `name_taken` / `category_name_taken`）；第 101 个 → 400（issue `tag_limit_reached`）；并发只有一个成功；**贴标签时自动建定义与 `POST /me/tags` 走同一把用户咨询锁**（并发 99 + 两个自动建定义，最终不超过 100）；说明 200 / 201 字边界正确。
- **判定**：通过／失败。

### T13 · 我的标签贴法

- **前置**：库条目生效；已有 19 / 20 个生效贴法；另有 20 个只含休眠贴法的定义；已有定义但未贴。
- **步骤**：贴已有定义、贴新名字（自动建定义）、贴第 21 个生效贴法、摘不在 skill 上的标签、归一化等价值；读 `skills my-tags` 的 `用在`。
- **期望**：已有定义直接贴；新名字建定义且无说明；第 21 个**生效**贴法 → 400（休眠贴法不计入 20，但定义计入 100）；摘不存在的 → 404 `TAG_NOT_ATTACHED`；归一化后相同视为同一个词；不产生版本。
- **判定**：通过／失败。

### T14 · 我的标签休眠与库归属

- **前置**：条目休眠（下线 / 移除 / 无当前版本）；一个可见但不在库的 public skill；一个不可见的 private skill。
- **步骤**：读三组词；贴 / 摘；读库列表计数；对「可见但不在库」写；对不可见写。
- **期望**：休眠条目的我的标签读不到（`readable=false`、`reason=dormant`）；写 → 409 `LIBRARY_ENTRY_DORMANT`；**可见但不在库 → 403 `forbidden` + `details[].reason = not_in_library`**，可加入的提示 `skill join`、下线的提示「现在加不进库」；**只读共享但条目休眠 → 409，不是 403**；不可见 → 404；计数不算；恢复后原样回来。
- **判定**：通过／失败。

### T15 · 公开标签的写

### T22 · 过滤组合与 SQL 谓词

- **前置**：足够大的夹具。
- **步骤**：分类多选取「或」、我的 / 公开标签取「且」、不同类取「且」、`source` 重复取「或」；`EXPLAIN` 检查过滤位置；同一夹具分别打 `/api/v1/skills`、`/categories`、`/public-tags`、`/me/tags` 的计数与 `source` 筛选。
- **期望**：组合结果与集合运算一致；标签过滤与访问谓词同在 SQL 的 `WHERE`，没有结果后过滤；**计数与 `source` 筛选读同一个 `identified` CTE**（`EXPLAIN` 里四处计划的谓词与 join 形状一致，不是各自重写一份）；分页与总数一致。
- **判定**：通过／失败。

### T23 · 排序与分页确定性
