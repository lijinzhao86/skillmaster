# v49-public-signals · 公域的可信与使用信号

> **最后更新**：2026-11-06
> **状态**：公域信号、使用度量（M15）与控制台 P3 已实现（2026-11-06）；文件行数闸已过；循环审计已闭合。T7 的人工对照未执行
> **含收费**：否

## 目标

公域 skill 不再只有描述与适用场景：补上**来源卡、许可证、使用信号**，重排信息页的层次，并让 CLI 读到同一组事实。来源按「适配器 + 通用信号」建模，接 GitHub、SkillHub 或下一个平台时只加适配器，不加字段、不改页面分支。许可证区分「已识别 / 仅声明 / 未声明 / 其他」，不把公开误读成随便用。细节见 [`prd.md`](prd.md)。

## 验收标准

摘要三条：公开 skill 能说清「谁给的、平台担保什么」；能说清「做什么、什么时候用、边界在哪」；能给出「有没有人在用、被用得多不多」的分桶信号，且 CLI 与控制台读到同一组值。完整验收见 [`prd.md`](prd.md) §验收与指标。

## 这一版明确不做什么

- **不做推荐排序**：排序仍按更新时间倒序；多信号排序与逐卡理由留到下一版。
- **不做官方策展**：精选集、编辑推荐语、场景货架留到下一版。
- **不做评测卡**：有/无 skill 的对照评测需要任务集与持续模型成本，单独一版。
- **不做用户反馈**：五星与「用成了/没成」都不在本版。
- **不做开源同步**：SkillHub / GitHub 的内容抓取与许可合规是下一版；本版只建来源模型与 GitHub 指标适配器。
- **不做作者 / 协作者的使用（`scope=owner`）**：今天没有作者看板；采集私有使用会扩大个人行为记录的面，与 ADR 0149 的最小数据口径冲突。作者看板那版再开 scope 与 ADR。
- **不做官方图标**：本版没有图标的数据来源与写入口，头像只有首字母 + 稳定底色；有生成与下发路径时再做。

完整清单（含「公域只搜不列」「不扩大公开范围」「收藏」）见 [`prd.md`](prd.md) §不做。

## 与目标态的关系

目标态是「公开市场 + 平台审核 + 可解释排序」。本版只做其中「平台背书之后，用户凭什么判断」的信息层，不改变公开范围（[ADR 0146](../../decisions/0146-public-is-platform-endorsement.md) 仍是唯一入口），也不把公域变成可整表拉取的目录（[ADR 0082](../../decisions/0082-public-and-private-with-my-library.md) 不动）。
