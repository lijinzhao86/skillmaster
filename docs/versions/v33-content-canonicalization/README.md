## 目标

在写入口把跨系统的差异抹平：文本统一成 LF / 去 BOM / UTF-8 / NFC，文件名按「任何系统都能还原」的规则校验，打包垃圾丢弃；做不到的**拒绝并说清改哪里**。细节见 [`prd.md`](prd.md)。

## 验收标准

A1–A10：归一化逐项、跨平台幂等、路径拒绝带路径与原因、碰撞给两个文件、垃圾丢弃并报告、审计留痕、网页新建时行内挡住且导入点名、旧版本不变、拒绝零落库、文案与 [`prd.md`](prd.md) §措辞 逐字一致。完整验收见 [`prd.md`](prd.md) §验收与指标，执行情况见 [`test-plan.md`](test-plan.md) §结果。

## 这一版明确不做什么

摘要四条最要紧的；**完整范围与每条的理由在 [`prd.md`](prd.md) §范围**。

| 不做 | 原因 |
|---|---|
| 不改旧版本 | 版本不可变（ADR 0064）；旧内容在复制成草稿再改时自然归一 |
| 不自动改名、不改写正文链接 | 改名要同时改所有引用，猜错一个就是悄悄坏掉 |
| 不做「接受但警告」 | 问题被推迟到下载那一刻，那时作者已经不在场 |
| 不统一文件末尾换行、不保存权限与时间戳 | 补一个换行是改内容；权限与时间戳包格式里没有，还原是另一个话题 |

## 与目标态的关系

[`target/`](../../target/) 里 skill 是可被任何客户端取用的一份内容。本版让「同一份内容」在 Windows / macOS / Linux 上真的是同一份。

- 保留的部分：内容寻址（ADR 0005）、版本不可变（ADR 0064）、`If-Match` 写前基线。
- 已经分叉的部分：ADR 0005 §后果里「上传时不得改写内容」这一句被 [ADR 0117](../../decisions/0117-content-is-canonicalized-at-the-door.md) 取代；读取路径仍原样服务存储字节。
