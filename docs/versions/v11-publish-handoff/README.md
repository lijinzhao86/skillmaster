# v11-publish-handoff · 把上线的决定交到它该去的那一栏

> **最后更新**：2026-10-21
> **状态**：已实现（三份文档成稿；CLI 与网页改动落地，`go test ./...`、`npm run test`、`npm run type-check` 全绿；真机验收见 [`test-plan.md`](test-plan.md) §结果）
> **含收费**：否

## 目标

CLI 把「去网页上确认上线」这件事交回给人时，把落点（哪一栏）和决定（这次改动影不影响旧调用）一起带过去，
让人打开就是动作所在的那一页，版本号已经是那一档对应的建议（与 agent 的判断一致）。细节见 [`prd.md`](prd.md)。

## 验收标准

一句话：交接句落在「操作」栏、带上改动性质，页面按它预选；不给新参数时旧地址与页面行为逐字不变，机器契约不变；
拒绝句按本版改成带落点。完整 14 条与判定方式见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：#1、#3、#5、#6、#12、#13——覆盖「落在动作那一栏」「决定真的到了页面」「交接句可复制」「四个动词都带落点」
「旧地址不变」「机器契约不变」。

## 这一版明确不做什么

- 不做 `--release <任意版本号>` —— 预填必须落在三个建议号之一，否则**一打开**单选那行的分类就是假话。
- 不让 CLI 执行上线 / 回滚 / 下架 / 重新上架 —— 它们改变调用者读到什么（[ADR 0061](../../decisions/0061-what-a-credential-may-do-to-versions.md)）。
- 不动服务端、接口与设计件的界面 —— 本版只在客户端拼地址、读地址，在三态之间选一个。

完整范围与每条的理由见 [`prd.md`](prd.md) §范围。

## 与目标态的关系

- **保留的部分**：服务端是唯一真相；上线等动作只在浏览器面由人确认；交接落到拥有动作的那一页（[ADR 0072](../../decisions/0072-the-handoff-points-at-the-page-that-owns-the-action.md)）。
- **这一版推进的部分**：交接从「哪一页」细到「哪一栏 + 预选」，边界由 [ADR 0074](../../decisions/0074-a-handoff-may-carry-a-preselection.md) 定下：**可以带预选，不能带执行**。
- **分叉**：目标态里的 MCP 适配器仍不在本版；本版只补 CLI 与单版页这条交接路径。
