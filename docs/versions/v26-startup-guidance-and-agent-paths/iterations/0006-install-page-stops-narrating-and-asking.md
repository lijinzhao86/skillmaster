# 0006 · 安装页不再播报过程、不问「要现在装吗」，「小工具」改称 CLI

- **日期**：2026-10-28
- **关联**：[0003](0003-first-contact-says-what-it-is-doing.md)、[`design/voice-spec.md`](../../../../design/voice-spec.md) §八、[`skillmaster-site/public/install/skillmaster.md`](../../../../skillmaster-site/public/install/skillmaster.md)、[`skillmaster-cli/install/README.md`](../../../../skillmaster-cli/install/README.md)

## 改了什么

- **过程状态不播报**：`voice-spec` §八 三条规则的第一条从「先说再查」改成「不问、不播报」；话术表删掉「正在下载，大概一分钟」那一行，检查与安装期间不再说进度。
- **装之前不再问「要现在装吗？」**：产品负责人判定「用户把开始那句发过来就是同意」，因此删掉请示那一行，以及「每一步动手前我都会先问你一声，随时能停」这类客套。
- **补了一行「改好 PATH」的交接**：`装过、但窗口找不到` 这条走完（改好 PATH、新开终端）之后原来没有对应的话——说「装好了」是假话，说「不用装」又把用户绕回去。新增第 8 行「现在能用了……」专用于这一支；话术表最终 14 行（`voice-spec` §八 的「话术停在哪」也写这个数）。**安装段专属的动作是「不问、不播报」**；`startup` 旅程里「挑了就是同意」那条由 [0004](0004-startup-skill-restructured-for-users.md) 定，不在本条范围。
- **`skillmaster-site/public/install/skillmaster.md` 按「装完即终点」重写**：`## 话术定稿`（14 行）之后是四步——开场 / 看一眼这台电脑 / 装 / 结果；结果只有两个出口：**装成了用第 6 / 7 / 8 行开头交接、再按登录状态接第 9 或 10 行，并把后面的交给 `skillmaster startup`**，没装成用第 11–13 行，仍不成用第 14 行停住。手工安装、地址说明、脚本失败对照退到附录。
- **`skillmaster-cli/install/README.md`（新增）**：安装路径的流程图与逐步对照表（步骤 / 用哪一句 / 自己做什么 / 停在哪），两个平台的目录与架构变量差异。
- **「小工具」改称「CLI」**（同一轮，按安装页走查定）：产品负责人判断「小工具」听起来业余，改用 `SkillMaster CLI`，第一次出现时补一句「一个装在这台电脑上的命令行工具」。落点：安装页的话术表与正文、本版 PRD / TD / test-plan / research、`skillmaster-cli/install/README.md`，以及当时 CLI 清单第一项的名字（`startup_plan.go` 的 `planItem`，该文件已在 v27 删除）。
- **安装页的检查与失败处理**：第 0 步只查能确定的两件（有没有对应的包、装过没有且是哪个构建——「命令找不到」必须区分「没装」与「装了但不在 PATH」）；「装不装得进去」不预检（目录常常还不存在），改成 `## 装的时候失败了，怎么讲` 一节，把脚本的三类失败翻成人话，并且每次都说清「什么都没装成、原来的东西没被动过」。

## 为什么

2026-10-28 按八个分支（装上 / 已装 / 装了但不在 PATH / 下载失败 / 校验不符 / 权限不足 / 缺依赖 / 不再支持的系统）逐个真机走安装页时发现：

1. **播报过程让人等**：先说「正在下载，大概一分钟」，用户就盯着那一分钟；不说也一样要等，而说错了时间反而失信。
2. **装之前的请示是多余的**：用户已经把「根据 <地址> 安装 SkillMaster。」发过来了，那就是同意；再问一次只是把同一个决定问两遍。
3. **有一条分支没有收尾的话**：改好 PATH、新开终端之后，agent 手里没有任何一句对得上现状的话——说「装好了」是假话，说「不用装」又把用户绕回去。
4. **「小工具」是个业余的说法**：同一个东西在别处都叫 CLI，安装页却叫「小工具」，用户第一次听到会以为是两个东西。

## 影响

- **只影响安装段**：`startup` 旅程的请示口径由 [0004](0004-startup-skill-restructured-for-users.md) 定（挑了就是同意 + 三处带推荐的提问），本条不改它。
- **`voice-spec` §八 是安装对话的权威**；控制台其余各节不受影响。
- **`skillmaster-cli/install/README.md` 随安装页一起维护**：安装页改了话术或步骤，这份对照表跟着改。
