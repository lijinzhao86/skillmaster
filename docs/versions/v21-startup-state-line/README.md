# v21-startup-state-line · 把「现在的位置」从数个数改成认名字

> **最后更新**：2026-10-26
> **状态**：已完成（已合入 `main`，随 CLI `1.0.1` 发布；单测全绿，**真机 T11 仍未执行**）
> **含收费**：否

## 目标

`skillmaster startup` 打印的状态行按**名字**判断本机的 skill 搬没搬过，并且线上与草稿都只算自己的。细节见 [`prd.md`](prd.md)。

## 验收标准

五条状态判定、两种平台读法各只算自己的、句子自证（「其中 N 个已上线」）、判不出来就不打印、不写步号。完整验收见 [`prd.md`](prd.md) §验收与指标。


## 这一版明确不做什么

摘要三条最要紧的；**完整范围与每条的理由在 [`prd.md`](prd.md) §范围**。

- 不比较 skill 内容 —— 同名不同内容算搬过，比较内容等于把导入流程塞进一行
- 不判断提示词写没写、验证跑没跑 —— 没有数据源
- 不为状态行翻页 —— 判不准时保守报「搬运」，等真有用户自己线上超过 50 条再说

## 与目标态的关系

[`target/`](../../target/) 描述的是完整形态。这一版是它的一个子集：

- 保留的部分：状态行是旅程的续跑点，只给阶段、不给步号（规则见 [v20 TD](../v20-guidance-on-platform/technical-design.md) §接口 › CLI；[ADR 0096](../../decisions/0096-guidance-lives-on-the-platform.md) 是旅程在平台上的决定）
- 已经分叉的部分：无新增分叉；本版只是把目标态要求的那一行从「数个数」修正成「认名字」
