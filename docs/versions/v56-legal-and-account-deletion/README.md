# v56-legal-and-account-deletion · 公开的法务文本与可执行的账号注销

> **最后更新**：2026-11-10
> **状态**：已完成（2026-11-10 合并 PR #161 并发布服务端、控制台、官网；**日志保留期部署项仍未执行**，见 [`test-plan.md`](test-plan.md) §结果）
> **含收费**：否

## 目标

让平台第一次拥有可公开访问的《隐私政策》《服务条款》，以及一条立即生效、可执行的账号注销路径：个人内容删除，协作与公开内容按归属保留。细节见 [`prd.md`](prd.md)。

## 验收标准

两个法务页面可匿名访问、页脚入口真实、注册必须显式同意、注销立即生效；30 天后个人数据与个人命名空间内容删除，别人命名空间里的贡献保留并显示「已注销账号」。完整验收见 [`prd.md`](prd.md) §验收与指标。

成立条件：**文本里写的保留期与内容归属必须与实现同一版上线**——文本是底稿，不能先于它所承诺的行为发布。执业律师审阅放在内测版上线之后（2026-11-09 定），重点看责任上限与免费服务的免责边界、公开市场许可与内容归属、去标识化披露；律师要求改动的，按新版本号重出并通知用户。

## 这一版明确不做什么

摘要四条最要紧的；完整范围与每条的理由在 [`prd.md`](prd.md) §范围。

- 不做注销冷静期 —— 已定立即生效，撤销会把「已注销」变成中间态
- 不做 CLI 注销命令 —— 高风险不可逆，按 ADR 0081 留在控制台并弹窗确认
- 不做个人空间分享的永久连续性 —— 分享不创造永久保留；删除 + 通知接收者，要连续性请放团队空间
- 不做公开市场所有权转出的实现 —— [ADR 0176](../../decisions/0176-publishing-transfers-ownership-out-of-the-personal-namespace.md) 只写原则，留给允许普通用户发布公开的那一版

## 与目标态的关系

[`target/`](../../target/) 描述的是完整形态，其中**没有单独描述法务页面与账号注销**。本版按公开上线的最低合规要求先落地：

- 保留的部分：账号与身份模型不变，手机号仍是登录凭据。
- 已经分叉的部分：target 未覆盖本版新增的公开文本、同意记录与注销语义；本版不改变目标态的其他设计。
