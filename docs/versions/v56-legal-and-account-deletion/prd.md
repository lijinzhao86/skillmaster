## 用户与场景

**谁在用**

- **准备注册的新用户**：在注册页填手机号、密码、用户名的人。
- **已注册用户**：想知道平台收集了哪些信息、保存多久、出问题找谁。
- **想离开的用户**：不再使用，要求账号与数据被删除的人。
- **外部检查者**：应用商店、合作方、监管或律师，核对平台是否具备公开的隐私政策、服务条款与注销路径。

**在什么场景下用**

- 注册前，用户在提交表单前点开《服务条款》《隐私政策》，确认自己同意的是什么。
- 使用中，用户想确认手机号、凭据、skill 内容与日志分别怎么处理。
- 想离开时，用户在控制台找到「注销账号」，完成确认后看到账号立即失效。
- 外部检查者访问 `https://www.skillmasterai.com/privacy` 与 `/terms`，无需登录即可读到完整文本与生效日期。

**现在的替代做法是什么**

- 页脚的「隐私 / 条款」是 `href="#"` 加 `data-noop`，另有同一件事的第三个占位「协议」，点了都没有反应；平台没有任何公开的法务文本。
- 注册页没有同意勾选，也没有链接；「注册即同意」只存在于口头理解里。
- 没有任何注销路径；用户只能发邮件请求，平台也没有可执行的数据处置口径。
- 备份保留期没有统一口径：凭据页写「备份保留 30 天」，RDS 自动备份实际是 7 天；账号注销这条路径也没有对应的承诺与实现。

## 范围

### 做

| # | 做什么 | 交付形态 |
|---|---|---|
| 1 | 《隐私政策》页面 | www 站 `/privacy`，无需登录；含生效日期与文本版本号 |
| 2 | 《服务条款》页面 | www 站 `/terms`，无需登录；含生效日期与文本版本号 |
| 3 | 页脚真实入口 | 「隐私」指向 `/privacy`，「条款」指向 `/terms`；删掉重复的「协议」 |
| 4 | 注册显式同意 | 注册表单加勾选框「我已阅读并同意《服务条款》《隐私政策》」，不勾不能提交；服务端记录同意的文本版本与时间 |
| 5 | 注销入口 | 控制台「账号」页新增「注销账号」；点击后弹窗，要求输入当前密码与用户名，两者都对才执行 |
| 6 | 注销语义 | **立即生效、不可撤销**：账号立即不能登录，个人命名空间下的 skill 立即不可调用（两个已知窗口见下方「『立即』的边界」）；**30 天保留期**满后删除个人数据与个人命名空间内容；访问日志按法律要求保留 **6 个月**；账号行去标识化保留，供别人内容里的作者引用 |
| 7 | 注销联动 | 该账号的全部会话立即失效；全部 API 密钥立即失效；个人命名空间下的 skill 对任何人不可调用；**被分享/被入库的接收者收到一条「作者已注销，skill 不可用」的通知**；30 天内不能用同一手机号或用户名重新注册 |
| 8 | 内容归属 | **个人命名空间**的内容（含已分享的）随注销删除；**别人命名空间里的贡献**保留、作者显示「已注销账号」；**公开/官方内容**保留、作者去标识化；已下载副本披露不收回 |
| 9 | 文本与实现一致 | 三处保留期口径（个人数据与个人内容 30 天、日志 6 个月、自动备份最多 7 天，随 RDS 周期）与四条内容归属，在文本、控制台文案与实现里一致 |
| 10 | 安全承诺 | 隐私政策含「我们如何保护你的信息」一节（§四）：密码只存哈希；关键操作留痕、内部访问受控；安全事件告知。受托处理写在「我们与谁共享」一并（§五）：不出售个人信息、不用于广告；受托方只有五家（阿里云短信、OSS、RDS、DashScope，华为云 KMS），且只按列明的目的处理。人侧使用文档（待办里的「面向人的使用说明书」）复述同一口径 |

### 不做

| # | 不做什么 | 为什么 | 什么时候可能做 |
|---|---|---|---|
| 1 | 注销冷静期 / 撤销 | 2026-11-09 定「立即生效」；冷静期会让「已注销」变成一个还需要状态机的中间态 | 不做 |
| 2 | CLI 注销命令 | 高风险不可逆操作，按 [ADR 0081](../../decisions/0081-every-console-operation-has-a-cli-command.md) 属于例外；2026-11-09 由产品负责人确认留在控制台 | 不做；除非将来有明确的批量注销需求 |
| 3 | 数据导出 / 可携带 | 本期用户量小，用公开邮箱人工受理即可满足「可以复制一份」的要求；自动化导出要另定格式与接口 | 用户量上来或律师要求时，vN+1 |
| 4 | 英文版 | 第一版用户与条款语言都是中文 | 有海外用户时 |
| 5 | Cookie 同意横幅 | 平台只使用必要的会话 cookie，没有跟踪与广告 SDK；隐私政策里说明即可，不需要弹窗 | 引入分析或广告 SDK 时 |
| 6 | 未成年人独立流程 | 条款写明「18 周岁以下需监护人同意；14 周岁以下儿童单独告知监护人」；不做年龄验证与独立注册流程 | 有面向未成年人的功能时 |
| 7 | 注销后的数据恢复 | 与「立即生效、不可撤销」同一决定 | 不做 |
| 8 | 用户内容转移给他人 | 注销后不提供 skill 转移或继承；这需要新的所有权模型 | 有明确需求时 |
| 9 | 公开面的举报与下架 | 归「举报与反馈入口」那条待办，不混进本版 | 单独开版 |
| 10 | 文本更新后的重新同意 | 本期只记录注册时的文本版本；文本更新不打断现有用户 | 有重大条款变更且律师认为必须重新同意时 |
| 11 | 个人空间分享的永久连续性 | 分享不创造永久连续性；地址绑在个人命名空间上，要保住地址就得永久保留用户名与命名空间。改为删除 + 通知接收者（2026-11-09 定） | 不做；要连续性请放团队空间，或等公开市场所有权转出 |
| 12 | 公开市场条目的所有权转出（实现） | 原则已写进 [ADR 0176](../../decisions/0176-publishing-transfers-ownership-out-of-the-personal-namespace.md)；这一版只写条款，不建市场命名空间、不改地址模型、不做 unpublish | 允许普通用户发布公开的那一版 |

**范围里不许出现「后续再看」「视情况而定」。** 不确定的进 [`technical-design.md`](technical-design.md) §开放问题，并且必须是一个**能回答的问法**。

## 验收与指标

### 验收标准

| # | 验收标准 | 怎么判定 |
|---|---|---|
| 1 | 未登录访客访问 `https://www.skillmasterai.com/privacy` 与 `/terms`，能读到完整文本、生效日期与文本版本号 | 两个 URL 返回 200；页面含生效日期与版本号；不需要登录 |
| 2 | 页脚的「隐私」「条款」可点击并分别到达上述两页；「协议」不再出现 | 点两处链接各到达正确页面；页脚 DOM 中没有「协议」 |
| 3 | 注册表单必须勾选同意才能提交 | 不勾选点提交：前端拦住并给出提示；绕过前端直接调接口：服务端拒绝并返回可识别错误 |
| 4 | 注册成功后，服务端记录同意的文本版本与时间 | 查询该用户：两个字段都有值，版本号与当前公开文本一致 |
| 5 | 控制台「账号」页能看到「注销账号」；点击后出现确认弹窗 | 登录后打开账号页，入口与弹窗都在 |
| 6 | 弹窗里密码或用户名任一不对，不执行注销；取消弹窗不改变任何状态 | 各试一次：账号仍可登录，skill 仍在 |
| 7 | 两者都对并确认后：当前会话立即失效，账号不能再次登录，且提示「账号已注销」而不是「密码错误」 | 注销后刷新控制台跳到登录页；用原手机号+密码登录，得到明确的已注销提示 |
| 8 | 注销后该账号的全部 API 密钥立即失效 | 用注销前签发的 key 调一个需鉴权的接口，返回未授权 |
| 9 | 注销后该账号命名空间下的 skill 对任何人不可调用 | 另一个账号 `skmr skill invoke <已注销命名空间>/<skill>` 失败，错误可读 |
| 10 | 30 天内不能用同一手机号或用户名重新注册；30 天后可以 | 注销后立即用原手机号注册被拒；把保留期配成短值跑一次，期满后注册成功 |
| 11 | 保留期满后，个人数据与个人命名空间内容被删除；账号行去标识化保留 | 用可配置的保留期（测试设为短值）跑清理任务；期满后 namespace/skill/version/credential/legal_consent 查不到，别人命名空间里的 `skill_grant`/`skill_library_join`/`skill_invitation`/`skill_access_request`/`my_tag_definition`/`skill_usage_day` 也不再指向该 id；`app_user` 行仍在，手机号与 email 为空、handle 是 `deleted-<id>`、显示名「已注销账号」、`purged_at` 已写，`dueForPurge` 不再选中它 |
| 12 | 隐私政策写的三处保留期（个人数据与个人内容 30 天、日志 6 个月、自动备份最多 7 天）与实际配置一致 | 逐条对照：文本、部署配置、代码里的保留期配置 |
| 13 | 隐私政策 §四「我们如何保护你的信息」与 §五「我们与谁共享」两节都在，承诺齐 | 页面读得到：§四有密码只存哈希、关键操作留痕与内部访问受控、安全事件告知；§五有不出售、不投放广告、五家受托方及其目的 |
| 14 | 别人命名空间里的贡献保留，作者显示「已注销账号」 | **前置能力今天还不可达**：普通用户不能在别人的命名空间建 skill（待办里的「命名空间成员可写」）。用测试夹具造一条 `created_by` 指向 A 的 `team` skill → 注销 A 并跑清理 → 该 skill 仍可读，`handlesOf` 对 A 返回「已注销账号」；真实路径等那条待办落地后补验。这一条**不算本版的成立条件**，因为生产里还没有能产生这种内容的路径 |
| 15 | 个人空间里被分享/被入库的 skill 删除后，接收者收到通知 | 分享一个 skill 给另一个账号 → 注销 → 对方通知列表里有一条「作者已注销，skill 不可用」 |

**成立条件**：第 1、2、7、11、12 条是**不满足就不算交付**——没有公开文本、没有真实入口、注销不生效、个人数据没删干净、文本与实现不一致，任何一条都意味着这次上线不能对外宣称合规。第 14 条是前瞻性回归（真实路径要等「命名空间成员可写」落地），用夹具守住实现，不列入成立条件。

**「立即」的边界**：立即生效指注销事务提交后新请求被拒。两个已知窗口实测存在、本版接受（见 [`test-plan.md`](test-plan.md) §已知问题）：一个在注销两步之间提交的发布能让一条 skill 多留到 30 天清理；会话撤销在事务提交之后，进程恰好在两者之间退出会留下一个可用会话。两者都极窄，要彻底关闭需给写路径与 `/web/**` 加逐请求账号状态检查，留到后续版本。

### 指标

本版是一次性合规能力，不设业务指标；只记一个可复核的事实：截至上线日，`/privacy` 与 `/terms` 都能匿名访问，且注册页的同意识别在服务端可查。

## 依赖与前置

- **外部依赖**
  - 执业律师审阅放在内测版上线之后（2026-11-09 定）：先上，再请律师看**责任上限与免费服务的免责边界**、**内容归属四条**、去标识化披露、公开市场的持续托管许可；审后要改的按新版本号重出并通知用户。

- **内部前提**
  - 两条 ADR 已写：**0175**（注销立即生效、30 天保留、账号行去标识化、内容按归属保留）与 **0176**（发布即转出个人空间，原则预留）。
  - `design/` 已补法务页、注册同意、注销弹窗的设计件（2026-11-09）。
  - RDS 自动备份 2026-11-09 核为 **7 天**，≤30，不需要改；文本写「备份最多 7 天」。
  - 访问日志要真的到 6 个月：nginx 今天只留 14 天，journald 无显式上限；两条都在本版部署项里改。
  - 通知：用 M14 的 `notification` 给被分享/被入库的接收者发一条「作者已注销」。
  - [ADR 0081](../../decisions/0081-every-console-operation-has-a-cli-command.md) 的注销例外已由产品负责人确认（2026-11-09）。
- **排除了什么前置**
  - 不依赖短信签名与模板：生产注册链路已验证（2026-11-09），注销不新增短信环节。
  - 不依赖举报与反馈入口：两件事分开。
