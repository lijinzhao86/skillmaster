## 用例

### T1 · 技能文件落位

- **前置**：一台没装过 SkillMaster 的机器；Agent 的技能目录里没有 `skillmaster/`。
- **步骤**：按 `/install/skillmaster.md` 走完第 2 步（装技能）。
- **期望**：技能目录下出现 `skillmaster/SKILL.md` 与 `sop/01-create.md` … `sop/06-install.md`，共 7 个文件；顶层没有多套一层 `skillmaster/skillmaster/`。
- **判定**：`find <技能目录>/skillmaster -type f | wc -l` 等于 7。

### T2 · 技能清单可见

- **前置**：T1 通过。
- **步骤**：新开一个 Agent 会话，让它列出可用技能。
- **期望**：列表里有 `skillmaster`。
- **判定**：输出包含该名字；描述里含「铁律」与 `skmr skills search`——那是它被设计来承载的查/调两步（ADR 0129），不是空描述。

### T3 · 全局记忆未被改写

- **前置**：记下 `~/.claude/CLAUDE.md` 的 sha256（文件不存在时记为 `absent`）。
- **步骤**：走完整个安装流程（装技能 → 装 CLI → `skmr startup`）。
- **期望**：sha256 与流程前相同；文件内不含旧说明的首句「SkillMaster 管我的全部 skill」。
- **判定**：两个哈希相等且 `grep -c 'SkillMaster 管我的全部 skill'` 为 0（旧块的原文如此，少一个「全部」就永远匹配不到）。**这是本版的成立条件。**

### T4 · CLI 可用

- **前置**：T1 通过。
- **步骤**：按 `sop/06-install.md` 装 CLI。
- **期望**：`skmr --version` 打印版本与提交号；`skmr auth status` 能回答登录状态。
- **判定**：`skmr --version` 退出 0（短名字找不到时用绝对路径，见文档第 4 步）；`skmr auth status` 能报出登录状态——**没登录时它退出 1 并说「本机没有凭据」**，那也是正确结果，不要按退出码判失败。**装上了但跑不起来时，按第 26 行说，不要说「什么都没装成」。**

### T5 · 技能包可复现

- **前置**：仓库里 `skills/skillmaster/` 完整。
- **步骤**：连续构建两次，比较 sha256。
- **期望**：两次相同。
- **判定**：两次的 sha256 相等（Linux 用 `sha256sum`，macOS 用 `shasum -a 256`）；且解包后的文件与 `skills/skillmaster/` 逐字节一致（`diff -r`）。

### T6 · 解包失败不留残骸

- **前置**：两种各一次——(a) 目标目录里**没有** `skillmaster/`；(b) **已有**一份 `skillmaster/`。两次都把技能目录设为只读（`chmod 500`）。
- **步骤**：按流程执行「2 · 装技能」的命令。
- **期望**：命令失败；对用户说的话包含三件——停在哪一步、什么都没装成、以后怎么继续；**已有旧技能的那一次，旧技能原样还在**（文件数与内容不变）。
- **判定**：失败后 `find <技能目录>/skillmaster -type f` 等于 7，且与失败前 `diff -r` 无差异；没有旧技能的那一次，目录不存在或为空；对话里三件齐。**再加一次「备份已建、新目录移入失败」的模拟**：旧技能要被移回原位，技能目录里不留 `.skillmaster-old.*`。

### T7 · startup 不再写记忆

- **前置**：新版 `skillmaster/skillmaster-startup` 已上线。
- **步骤**：`skmr skill read skillmaster/skillmaster-startup SKILL.md`，通读正文。
- **期望**：不存在「写进记忆」「全局记忆」「那段说明」这类步骤；登录与导入技能的步骤仍在。
- **判定**：全文 grep 不到上述词；`skmr startup` 跑一遍后 T3 的检查仍成立。

### T8 · 用户级优先

- **前置**：准备两个位置——Agent 的用户级技能目录，以及一个**项目**里的技能目录。
- **步骤**：在一个项目目录里启动 Agent，按流程装技能。
- **期望**：`skillmaster/` 出现在用户级目录；项目的技能目录里没有它。
- **判定**：两个位置各自 `find` 一次；并且在这个项目里新开会话，技能清单仍能看到 `skillmaster`。

### T8b · 只有项目级目录的客户端

- **前置**：一个只有项目级技能目录、没有用户级目录的客户端（本机不可复现，走查模拟）。
- **步骤**：按流程装技能。
- **期望**：装进当前项目的技能目录；第 7 行之后补第 24 行「只在这个项目里生效」。
- **判定**：当前项目目录出现 `skillmaster/`；对话里有那句话。

### T9 · 装完说明「自动查找」与「强制调用」

- **前置**：T1 通过。
- **步骤**：走完技能安装那一步。
- **期望**：对用户说清三件事——平时 Agent 会自己按需查找；要强制调用时输 `/skillmaster`；这个技能只对这台电脑的这个 Agent 有效，换电脑或换 Agent 要再装一次。
- **判定**：话术定稿里有这三句，且装机记录（对话文本）里确实出现过。

### T10 · 前提不满足时，在欢迎之前停下

- **前置**：两种走查各一次——(a) 一个不能装技能的客户端；(b) 一台 32 位、Windows 10 1803 以下、没有 `curl.exe` / `tar`，或这个架构没有对应包的机器。
- **步骤**：开始按流程走，看它的第一句输出。
- **期望**：第一条话术就是对应那一句——(a) 第 22 行「还不支持装技能」；(b) 第 16 行「这台电脑装不了」。**都在欢迎之前**判掉：没有第 1 行开场白，没有确认，没有任何安装动作。
- **判定**：没有出现下载或解包命令；失败那一支给的是 `另想办法` / `先到这里` 的选项卡；选「另想办法」且给不出替代时走第 25 行（纯文字、没有选项卡）；选「先到这里」之后只有结束语。
- **备注**：真实客户端无法在本机复现，本条以走查为准；拿到真客户端后应补一次真机记录。

### T11 · 判断不出技能目录

- **前置**：一个无法确定用户级技能目录的走查会话（模拟该分支）。
- **步骤**：按流程走到「2 · 装技能」。
- **期望**：它**不装**，说第 23 行（「我暂时判断不出自己该把技能放在哪里」），给 `继续` / `先到这里` 的选项卡；**不问用户路径**，也不装进项目目录。
- **判定**：对话里没有安装命令、没有「你告诉我路径」这类问句；话术与第 23 行一致；选「继续」但查不到时走第 25 行（纯文字、没有选项卡）。

### T12 · Windows 上装技能

- **前置**：一台 Windows 10 1803 及以上、PowerShell 5.1 的机器（`curl.exe` 与 `tar` 从 1803 起自带）。
- **步骤**：按「2 · 装技能」的 Windows 命令下载并解包；用 `Get-ChildItem` 数文件。
- **期望**：解包成功、文件数为 7；`tar` 不需要额外安装。
- **判定**：命令退出码为 0、计数为 7。
- **备注**：本机没有 Windows 机器，**本条未执行**。文档里的 Windows 命令是按 bsdtar 与 PowerShell 行为写的，不是实测结论。

### T13 · 下载地址在本机 curl 上可用

- **前置**：`site.yml` 的部署已经把技能包与安装说明都传到下载桶（`beta/skillmaster.tgz`、`beta/skillmaster.md`）。
- **步骤**：用**系统自带的** curl（不是 Python、不是浏览器）下载两次：`curl -fsSL https://skillmaster-dl.oss-cn-hangzhou.aliyuncs.com/beta/skillmaster.tgz -o /tmp/skillmaster.tgz`，以及 `curl -fsSL https://skillmaster-dl.oss-cn-hangzhou.aliyuncs.com/beta/skillmaster.md -o /tmp/skillmaster.md`。
- **期望**：两条都退出 0；tgz 的 sha256 与本地构建的产物相同、解包后 7 个文件；md 与 `skillmaster-site/public/install/skillmaster.md` 逐字节相同。
- **判定**：两条命令都退出 0、tgz 的 `shasum -a 256` 相等、`find -type f | wc -l` = 7、md 的 `cmp` 无输出。
- **备注**：这一条守的是「地址选对了」——`www` 对只用 TLS 1.2 的客户端会重置，桶不会。上线前必须真跑一次。

## 环境与数据

- **环境怎么造**：Claude Code 用一个临时 `CLAUDE_CONFIG_DIR`，里面没有 `skills/skillmaster/`；系统用户目录保持原样，用来观察它会不会被改。
- **数据**：技能源来自 `skills/skillmaster/`；tgz 来自本地构建或下载桶；哈希工具：macOS `shasum -a 256`，Linux `sha256sum`。
- **清理**：删掉临时 config dir 与被测试的技能目录；只读目录先 `chmod 700` 再删。
