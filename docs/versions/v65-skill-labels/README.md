# v65-skill-labels · 公域 skill 的标签、分类与预期结果

> **最后更新**：2026-11-14
> **状态**：进行中（**P0 已实现**：词表、读模型、筛选、CLI 与生产控制台；P1 抽取 / P2 抽样未交付）
> **含收费**：否

## 目标

给公域 skill 加一组**可扩展的属性标签**、**13 个一级分类**与一句「预期结果」，让用户在搜索结果里更快判断「是不是我要的」；标签由 Agent 自动打、按抽样验收。细节见 [`prd.md`](prd.md)。

## 验收标准

13 个一级分类与旧 10 个的映射可查；2 个属性维度（运行环境多选、定价）可展示、可筛选；结果行显示作者描述、`outcome` 在信息页；控制台不显示公域计数（分类菜单、公开标签清单行内、搜索结果页头与分页条），结果页有自己的头与「清除」、与推荐可区分；三档抽取与每周 30–50 条、准确率 95% 的抽样验收跑通；网页与 CLI 读同一组字段。完整验收见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：验收 #1（13 类词表与旧类映射）、#3（每个标签有来源与证据）、#4（结果行用描述）、#7（抽样验收）、#13（运行环境多选）、#14（`gpu` / `docker` / `database` 的严格口径）任一条不满足就不算交付。

## 这一版明确不做什么

摘要三条最要紧的；完整范围与每条的理由在 [`prd.md`](prd.md) §范围。

- 不做二级目录 —— 用户靠搜索，不靠翻目录；96 个二级词转成候选标签，不做层级
- 不做安全扫描、许可校验、举报下架 —— 属于另一条治理线，不阻塞标签与分类
- 不做评价、评分、评测视频 —— 它们是「证据」与「评价」层，与 `outcome` 的主张层分开，留给后续版本

## 与目标态的关系

[`target/design.md`](../../target/design.md) §2.8 的治理模型有「扫描、举报下架、实名、审核队列」等完整形态。这一版只做其中的**标注与呈现**一小块：分类、属性标签、预期结果，以及它们的自动生产与抽样验收。

- 保留的部分：治理模型的「谁标、标什么」这一层；其余（举报、下架、评测、评价）不变。
- 已经分叉的部分：无。这一版不改变任何已有的公开/私有或生命周期决定。
