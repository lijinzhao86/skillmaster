# v15-marketing-home · 公开营销首页

> **最后更新**：2026-10-24
> **状态**：进行中——**代码已实现**（2026-10-24，见 [test-plan](test-plan.md) §结果），**未交付**：视觉验收、部署与推送上 CI 尚未做
> **含收费**：否

## 目标

在 `www.skillmasterai.com` 交付一个极简的静态营销首页：首屏是一句品牌主句、一句让 agent 下载并安装 CLI 的 prompt，以及紧接其下的三张解释「随时在场」的卡片；下滑一屏是产品 / 文档 / 关于页脚；`登录` / `开始使用` 交给控制台，**登录之后回来，导航认人**（`进入控制台` + 账号）。细节见 [`prd.md`](prd.md)。

## 验收标准

首页在 `www` 上可访问：**没有登录面，只有一次只读的会话查询**（[ADR 0086](../../decisions/0086-the-homepage-reads-the-session.md)），导航随会话在两种态之间切换，入口正确指向 `console`，并与设计稿逐处一致。完整验收见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：**「首页只读一次会话、不发起任何写」「入口指向 console 的 `/login` / `/register` / `/`」「带 console 会话访问首页确实看到已登录态」三条不满足就不算交付**——第三条是前两条的端到端证明：少了 cookie `Domain` 或那条 CORS，请求照发、入口照对，而首页会安静地永远显示未登录。

## 这一版明确不做什么

完整范围与每条的理由在 [`prd.md`](prd.md) §范围。

- **不做首页登录浮层 / 表单** —— www 只读会话，不写；跨源 CSRF 契约成本高，DeepSeek 的 www 也没有登录面
- **不做首页上的会话写**（登录 / 注册 / 退出）—— 这些都在控制台完成
- **不做文档 / CLI / 协议 / 更新日志的真实页面** —— 先保留占位链接，后续在同一个 `skillmaster-site` 里补
- **不做深色首页** —— 设计稿只有浅色态，这是一处有意分叉

## 与目标态的关系

[`target/`](../../target/) 描述的是完整形态，**没有单独描述营销首页**；这一版是产品的公开入口，不新增任何产品能力（托管、发现、库、标签都不变）。

- 保留的部分：把「版本、权限、一行加载」讲清楚的门面作用
- 已经分叉的部分：无。`target/` 里的组织、付费等差异与本版无关

## 影响最大的未决问题

完整列表见 [`technical-design.md`](technical-design.md) §开放问题。按重要性排前三条：

1. **生产域名与 apex 行为**（`www` / `console`，apex 301）——影响链接与证书，实施前要核 DNS；它也是会话 cookie 的 `Domain` 与那条 CORS 的输入，域名不对这两处会一起失效。
2. **占位链接最终指向哪里**（文档 / CLI / 协议 / 关于 / 更新日志 / 隐私 / 条款）——本版保留占位，但落点决定后续站点结构。
3. **静态托管的未知路径行为**（404 还是回 index）——影响分享出去的坏链接。
