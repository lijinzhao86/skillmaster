## 目标

用户或 agent 用一段自然语言，给库里的一条 skill 补「我会在什么时候用它」；字段名复用作者的 `when_to_use`，不新造概念。库内检索按证据分级把这个补充排在作者内容之前、名字/标题之后。**同一版把 `SKILL.md` 的三个文本上限一次收口**：`description` 1024、作者 `when_to_use` 200、我的适用场景 200，全部按 Unicode 码点。细节见 [`prd.md`](prd.md)。

## 验收标准

写入 / 私有 / 入库闸 / 检索生效 / 公域不变 / 离线指标。完整验收见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：离线评测的改写组 `Recall@5` 与个人触发组 `Top-1` 不达标，就不算交付。

## 这一版明确不做什么

- 不做「不适用场景」——只做正向；反向需要独立的抑制机制与语义，本版不设计。
- 不做同义词表——换说法交给语义，不维护人工词表。
- 不做训练 / LTR——只记录样本，不训练；模型在后续版本单独评估。
- 不做拒绝回执的邮件汇总——本版只做拒绝并跳过与日志；运营邮箱、频率与隐私口径未定，记在 [`TODO.md`](../../current/TODO.md)。

## 与目标态的关系

[`target/`](../../target/) 没有「个人适用场景」这一层；v14 的私有库是它的前置。本版在私有库之上新增一层**只对本人可见、参与库内排序**的触发文本。这条差异目前记在这里，交付后由目标态文档的差异清单吸收。
