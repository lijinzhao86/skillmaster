## 目标

交付本人的交互明细、所有者的聚合与协作者统计，以及一份内部可查的完整行为日志；公开面仍只给分桶。范围、四层可见性与验收都在 [`prd.md`](prd.md)。

## 这一版明确不做什么

| 不做 | 原因 |
|---|---|
| 向任何人展示别人的明细 | 明细是可还原的个人行为（ADR 0149） |
| 公开面给精确人数 | ADR 0149：小样本可反推具体的人 |
| 给所有者看协作者的搜索词或读取/写入次数 | 产品负责人已定：使用者表只统计调用次数 + 提交版本数（采用 + 贡献） |
| 内部分析看板、报表、导出 | 先走 SQL；专用工作台归「运营侧策展工作台」 |
| 按条删除 / 清空历史 | 行为日志是内部安全与审计记录，按保留期保存；账号注销不删除（2026-11-10 用户定） |
| 匿名行为、IP / UA / 设备指纹 | 所有读写都要求登录 |
| 把整版下载展示成「调用」 | 调用口径 = `invoke` |
| 把搜索与调用分成两份互不相干的列表 | 分开回答不了「搜到的和用的是不是同一条」 |
| 在明细默认视图里铺返回结果 | 日志表默认收起；下拉才看榜单 |
| 本版接 SLS / 独立实例 / TimescaleDB | 现阶段同实例最省；迁移触发条件见研究文档 |

## 验收标准

一句话：本人看得到自己的**交互明细**（搜索词 → 返回结果 → 实际调用与原名次）、别人看不到；所有者看得到聚合与协作者统计、看不到明细。细节见 [`prd.md`](prd.md) §验收与指标。

## 与目标态的关系

`docs/target/design.md` §2.7 的「作者看板」与「平台看板」是目标态；本版只做「本人明细 + 所有者聚合 + 协作者统计」，不做作者侧漏斗看板与平台侧分析。
