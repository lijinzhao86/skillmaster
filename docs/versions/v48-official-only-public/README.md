# v48-official-only-public · 公开只留给官方

> **最后更新**：2026-11-05
> **状态**：进行中（**已实现**；服务端 585 个用例、控制台 677 个用例全绿；A6/T8 公开搜索已端到端验证，`/web/discover` 与标签计数未单独驱动；待提 PR 与视觉验收）
> **含收费**：否

## 目标

公开（`visibility = public`）只能由 `namespace.official = true` 的命名空间（今天只有种子里的 `skillmaster`）设置；其他命名空间一律拒绝，存量的非官方公开 skill 一次性转私有。细节见 [`prd.md`](prd.md)。

## 验收标准

九条验收（A1–A9），摘要三条：非官方设公开被服务端拒绝且原值不变；官方仍能公开与收回；存量迁移后非官方公开行为零、官方不受影响。完整验收见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：A1（非官方写入被拒绝）与 A5（存量清零）不满足就不算交付——这一版要解决的就是「公域里不再出现没有背书的 skill」。

## 这一版明确不做什么

摘要三条最要紧的；**完整范围与每条的理由在 [`prd.md`](prd.md) §范围**。

- **不做用户公开的申请 / 审批流** —— 没有责任主体与审核流程；先关闭入口，将来开放要新开 ADR。
- **不删除存量 skill** —— 转私有已足够退出公域；删除不可逆，内容仍属于作者。
- **不做公域信息增强与开源同步** —— 那是随后两版的事；本版只解决「谁能公开」。

## 与目标态的关系

[`target/`](../../target/README.md) 描述的是完整形态：公开市场、作者可选择公开、平台审核。这一版保留「公开即被搜到、可被调用」，但把公开的主体收窄为平台自己，尚未做目标态的审核队列。

- 保留的部分：公开与私有两态（[ADR 0037](../../decisions/0037-visibility-has-two-states.md)）、公开后陌生人拿到的档位（[ADR 0048](../../decisions/0048-visibility-hands-out-a-rung.md)）、公域只搜不列（[ADR 0082](../../decisions/0082-public-and-private-with-my-library.md)）。
- 已经分叉的部分：目标态允许作者公开并设审核状态；本版只允许官方公开。差异登记在 [`target/README.md`](../../target/README.md) 的差异清单。
