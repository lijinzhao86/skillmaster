# v29-cli-rename-to-skmr · 命令行改名 `skmr`

> **最后更新**：2026-10-29
> **状态**：进行中（**已实现，未提交**；等循环审计与合并）
> **含收费**：否

## 目标

把 CLI 的命令名从 `skillmaster` 改成 `skmr`；旧名只在代码里留一处兼容（一个常量 + 一个入口），文档与界面不写它。细节见 [`prd.md`](prd.md)。

## 验收标准

装完就能用 `skmr`；面向人的输出只写 `skmr`；自更新按新名取包与替换；文案面全部换新。完整 8 条见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：验收 1（装完就能用）、3（输出只写新名）、8（安装脚本装不上时说的话是对的）——任一条不满足，这一版等于没交付。另外，Windows 上的安装没有机器跑（T9 记「未执行」）。

## 这一版明确不做什么

摘要三条最要紧的；**完整范围与每条的理由在 [`prd.md`](prd.md) §范围**。

- 不改仓库名 / Go module / 域名 / 配置目录 —— 它们不是命令名，改它们是另一件事
- 不在文档与界面里维护两个名字 —— 旧名只是代码里的一行兼容（[ADR 0113](../../decisions/0113-the-cli-is-called-skmr.md)）
- 不借机改任何命令的行为、参数或输出形状 —— 这一版只换名字

## 与目标态的关系

[`target/`](../../target/) 没有关于命令名的规定，这一版不分叉。`docs/target/README.md` 的差异清单不需要新增条目。
