# v29 · 本版范围外的已知缺陷

这些是**历史代码里**的问题：它们不是这一版引入的，这一版也不修（只把命令名换成 `skmr`）。每一条都标了状态与复现。

## 1 · 控制台让人跑一条不存在的命令

| 项 | 内容 |
|---|---|
| 在哪 | `skillmaster-console/src/pages/SkillPage.tsx`（文件视图里的「二进制文件」提示） |
| 原话 | 「这是二进制文件，不在这里展示。本机用 `skmr skill get` 取它。」 |
| 问题 | **`skill get` 不存在。** 命令表里没有这个动词（`skillmaster-cli/cmd/skillmaster/declarations_skill.go` 里没有 `get`），跑它会得到「不认识的子命令」。 |
| 状态 | **已复现**（2026-10-29：命令表 grep 无 `get`；设计件里也没有这句——它是实现时加的，不在设计稿里） |
| 为什么这一版不修 | 换名与「该让人跑哪条命令」是两件事。按仓库流程，改界面文案要先改设计件，而设计件在这一处根本没有这句话；正确做法是先把那一态补进设计件，再改产品。 |
| 修的时候要知道 | 真正能取到文件内容的候选是 `skill read` / `skill cat`；能整包下载的是 `skill download`（会写一个目录）。选哪个取决于那一屏想让人做什么。 |

## 2 · golden 对比只认「有没有差」，不认「差成什么样」

| 项 | 内容 |
|---|---|
| 在哪 | `skillmaster-cli/cmd/skillmaster/golden_test.go` 与 `testdata/golden/expected-changes.json` |
| 问题 | 一个 (用例, 字段) 一旦列进表里，测试就只确认「它与改前的快照仍然不同」。**这个字段之后再变一次，测试不会发现**——它不比较差异的内容。 |
| 状态 | **已复现**（2026-10-29）：`index.json` 里含旧名的用例共 9 个，其中 8 个早已在表内，因此它们这一版的改名不是被这条测试抓住的，是被守卫与 grep 抓住的。 |
| 为什么这一版不修 | 这是测试自身的形状，与换名无关；要修得改成「记录当前输出」的机制，那是一笔独立的活。 |
| 影响 | 本版的验收 3 因此**不**把 golden 测试当证据。 |

## 3 · 这台机器访问不了 `www.` 与 `console.` 两个域名

| 项 | 内容 |
|---|---|
| 现象 | 从这台开发机 `curl https://www.skillmasterai.com/`、`https://console.skillmasterai.com/` 都是 TLS 重置；HTTP 返回备案提示页。`dl.skillmasterai.com` 同样。 |
| 状态 | **已复现**（2026-10-29，与更早的部署记录一致） |
| 与本版的关系 | 本版改的是命令名与文案；线上的人工验收（点开安装说明、看控制台文案）必须换一个网络做。 |
| 为什么不在这一版修 | 它是域名与备案/证书的事，与 CLI 改名无关。 |
