# v40-code-writing · 文档与注释按「一个事实一个家」重构

> **最后更新**：2026-11-02
> **状态**：进行中（P0–P3 已实现，测试已跑；待评审。本版只改文档与注释，不改任何代码）

## 目标

按 [`lijinzhao/code-writing`](https://console.skillmasterai.com/skills/lijinzhao/code-writing) 的规范重构本仓库的全部工程文本：文档分家为「现状 / 历史 / 决策」，索引改为生成，注释只保留只对这一处成立的细节。细节见 [`prd.md`](prd.md)。

## 验收标准

九条可判定的标准（A1–A9），摘要其中四条：`docs/current/` 成为唯一现状权威且全仓无失效链接；三个索引由脚本生成且 CI 比对通过；134 条 ADR 的索引与文件头零不一致；被改的代码文件里**没有任何一行非注释改动**。完整验收见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：A9「不改代码」不满足就不算交付——这一版的价值在于证明文本可以独立重构。

## 这一版明确不做什么

摘要三条最要紧的；**完整范围与每条的理由在 [`prd.md`](prd.md) §范围**。

- 不重写 v1–v39 的历史文档 —— 冻结比改写便宜，且改写会让历史变成今天的理解。
- 不做一次性注释大扫除 —— 只清规则能判定、且审计最频繁的部分。
- 不改任何产品行为、接口、表结构、前端 —— 代码行零改动。

## 与目标态的关系

[`target/`](../../target/) 描述产品完整形态，与文档结构无关。这一版不动 `target/` 的内容，只把它纳入统一的索引。
