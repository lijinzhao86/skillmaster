# v63-home-subdomain · 首页临时挂到 home 子域，许可证后 301 回 www

> **最后更新**：2026-11-13
> **状态**：进行中（设计已定稿；本版先交付 P0 准备，P1/P2 等许可证进程）
> **含收费**：否

## 目标

给营销首页增加一个同一注册域下的临时入口 `home.skillmasterai.com`，让 `www.skillmasterai.com` 可以腾出来办经营性 ICP 许可证；许可证下来后把 `home` 用 301 指回 `www`。细节见 [`prd.md`](prd.md)。

## 验收标准

七条验收（A1–A7），摘要其中三条：`home` 能通过真实证书提供与 `www` 相同的首页；控制台的品牌、退出与注册页法务链接指向当前入口；《隐私政策》的适用范围不再依赖子域枚举，且页面与服务端记录的版本同为 `1.2`。完整验收见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：本笔交付 P0，A1（`home` 可用）、A2（证书覆盖 `home`）、A6 的 P0 一次（巡检与探针有效）与 A7（法务版本同版）不满足就不算交付；A3、A4 属于 P1，A5 属于 P2。

## 这一版明确不做什么

摘要三条最要紧的；完整范围与每条的理由在 [`prd.md`](prd.md) §范围。

- 不用 `skillmasterai.cn` —— 独立顶级域要新增网站备案，审核期不能对外服务，跨域也共享不了登录态（时限口径见 prd §用户与场景）
- 不新增 `dl.` / `console.` 的域名与 server 块 —— 主证书会重签以加入 `home` 的 SAN，`console` 仍在覆盖范围内，重签后要复验
- 不做 canonical、sitemap 等 SEO 搬家 —— 临时宿主，切回时的 301 会自然收口

## 与目标态的关系

[`target/`](../../target/) 描述的是**完整形态**。这一版不新增产品能力：改营销首页的接入地址，并澄清《隐私政策》的适用范围与版本。

- 保留的部分：首页结构、控制台、下载入口、会话模型都不变；法务页只改适用范围那一句与版本号。
- 已经分叉的部分：无。

## 影响最大的未决问题

完整列表见 [`technical-design.md`](technical-design.md) §开放问题。五条已定（2026-11-13）：P1 时机另定、CORS 只放行一个来源、切回后 `home` 长期保留 301、站点发布探针跟随跳转不随 P2 改名、隐私政策去掉子域枚举并升 `1.2`。

仍开放的一条是 P1 切换时 `www` 的处理：倾向 301 到 `home`；若管局要求 `www` 不得指向本站内容，改为静态说明页——那张页在 `design/` 里没有设计，做之前先补设计稿。它只影响 P1 的形状，不影响本笔 P0 的交付。
