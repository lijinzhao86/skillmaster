# v63-home-subdomain · 首页主入口改为 home，www 作为独立页面保留

> **最后更新**：2026-11-13
> **状态**：进行中（P0 已上线；P1 正在本次改动中）
> **含收费**：否

## 目标

给营销首页增加一个同一注册域下的入口 `home.skillmasterai.com`，并把它作为主入口；`www.skillmasterai.com` 作为一个独立页面保留——内容不改、照常可访问，但任何页面都不链到它。两个宿主都要保留登录态，因此 CORS 来源从「一个」改为「显式列表」。细节见 [`prd.md`](prd.md)。

## 验收标准

七条验收（A1–A7），摘要其中三条：`home` 能通过真实证书提供与 `www` 相同的首页；控制台的品牌、退出与注册页法务链接指向 `home`；`www` 保持可访问且任何页面都不链到它。完整验收见 [`prd.md`](prd.md) §验收与指标。

**成立条件**：P0 的 A1（`home` 可用）、A2（证书覆盖 `home`）、A6 的 P0 一次（巡检与探针有效）与 A7（法务版本同版）不满足就不算交付；A3、A4、A5 在 P1 完成时验收。

## 这一版明确不做什么

摘要三条最要紧的；完整范围与每条的理由在 [`prd.md`](prd.md) §范围。

- 不用 `skillmasterai.cn` —— 独立顶级域要新增网站备案，审核期不能对外服务，跨域也共享不了登录态（时限口径见 prd §用户与场景）
- 不改 `www` 的页面内容 —— 所有者要求它先保持原样；它现在只作为独立页面保留
- 不新增 `dl.` / `console.` 的域名与 server 块 —— 主证书会重签以加入 `home` 的 SAN，`console` 仍在覆盖范围内，重签后要复验

## 与目标态的关系

[`target/`](../../target/) 描述的是**完整形态**。这一版不新增产品能力：改营销首页的主入口、把 CORS 来源改成显式列表，并澄清《隐私政策》的适用范围与版本。

- 保留的部分：首页结构、控制台、下载入口、会话模型都不变；法务页只改适用范围那一句与版本号。
- 已经分叉的部分：无。

## 影响最大的未决问题

完整列表见 [`technical-design.md`](technical-design.md) §开放问题。已定（2026-11-13）：`home` 是主入口、`www` 独立且内容不改、CORS 来源是显式列表、不再按原计划把 `home` 301 回 `www`、站点发布探针跟随跳转且不随阶段改名、隐私政策去掉子域枚举并升 `1.2`。

仍开放的一条是**许可证下来后 `www` 与 `home` 的长期关系**：`www` 是否继续作为独立页面、还是要 301 到 `home`，取决于许可证办理方的要求。它不影响本次交付。
