# 0051 · 作者面按档位分，不按面分

- **状态**：已采纳
- **日期**：2026-10-17
- **所属版本**：[`v5-skill-management`](../versions/v5-skill-management/README.md)
- **依赖**：[0047](0047-permissions-are-a-ladder.md)（权限是一条梯子）、[0034](0034-skill-level-sharing.md)（共享是 skill 级的授权）
- **修订**：[0031](0031-submitting-and-publishing-are-two-actions.md) §决定 8——「**可见性按面分，不按人分**：消费面（`/api/v1`，Bearer）只看得到 `published` 的版本；作者面（`/web`，会话）看得到自己的全部版本」。**该 ADR 正文四段保持原样**，改动记在这里。
- **取代**：[0034](0034-skill-level-sharing.md) §后果 里的一句——「**`viewer` 不进作者面**——只读的人走消费面，看不到草稿」。**该 ADR 正文四段保持原样。**

## 背景

[ADR 0031](0031-submitting-and-publishing-are-two-actions.md) §决定 8 把两个平面划得很干净：消费面只给已上线的东西，作者面连同草稿一起给。它自己的理由是「**面本身是访问控制的一部分**」——所以判定写在**链**上（`SecurityConfig` 把 `/web/**` 与 `/api/v1/**` 分给两套凭据），而不是写在每个响应里。

那条分界成立的前提是：**进作者面的人只有作者**。当时的共享只有 `viewer` / `editor` 两档，而 [ADR 0034](0034-skill-level-sharing.md) §后果 明确把只读的人挡在作者面之外——「只读的人走消费面，看不到草稿」。

梯子把那个前提拆了。设计件给「浏览」档写下的能力里有一句 **「网页上也能打开」**，而同时给「调用」档写下「**网页上看不到它**，只能用 agent」。两个平面之间因此多出一条**按档位**的线：`浏览` 及以上进得去那一屏，`调用` 进不去。

> **2026-10-17 同日修订**：这半句的「进不去」被推翻了——`调用` 也进得去，看得到**「信息」与「版本」两栏**（版本只列已上线，见 §决定 2a）。推翻它的理由不是设计偏好：那一档通过 `/metadata` **本来就拿得到**这一层（那个端点的门槛就是 `invoke`），所以给他一面只显示它的网页，不泄露任何他没有的东西；而他进不去文件清单，ADR 原有的那条担心（看到草稿）仍然成立，由 2a 与 §决定 2 一起挡住。背景里这句留着，它记录的是当时的问题。

而控制台那一屏**是作者面**——它列的是全部版本（含草稿）、带 diff、带设置。于是「浏览」档的人一进得去，就会看到他不该看到的东西：**还没上线的草稿**。

摆上桌的选项：

| | 做法 | 为什么被否 |
|---|---|---|
| a | 保持按面分，把设计件那一格的「网页上也能打开」删掉 | 那是「浏览」档的**定义性**能力——源稿的注释给了理由：「`浏览` adds the listing — and with it the web page, **because a page with no tree has nothing to be**」。删掉它，「公开 · 浏览」与「公开 · 调用」在网页面上就**没有差别**了，而设计件专门画了那个三选一 |
| b | **作者面的读按档位给内容** | 采纳 |
| c | 另开一个只读的浏览页，控制台那一屏仍是纯作者面 | 新画一整屏，而它属于「公共发现」那一块的形状（本版 §不做 #5），会把那一块提前拉进来 |

## 决定

1. **作者面的读端点按档位给内容**，不再「进了这个面就看到全部」。同一个地址对不同档位的人可以给出不同的**元数据**。
2. **逐条**：
   - **2a ·「信息」那一栏（元数据）→ `invoke`。** 它是 `/metadata` 那一层里**给「要不要用它」看的那一部分**：描述、适用场景、运行环境、版本名——够一个人（或他的 agent）判断这个 skill 适不适合、要不要调。（`allowed-tools` 不在这一栏：它是给宿主的授权，我们这里没有执行层，摆在页面上会被读成「我们放行了什么」——见 `design/README.md` 里 `allowed-tools` 那一节。）剩下的细节（名字、完整 digest、许可、`metadata` 原文）在 **设置 › 详细信息**，跟着 `admin` 走，所以 `调用` 档在**这一屏上**看不到它们，也不需要（这是界面规则；`/metadata` 那条 API 照旧给完整的 `frontmatter` 与 `digest`，本版不改）。**「版本」那一栏也给 `调用` 档**（2026-10-17 补），但**只列已上线的**——草稿仍然要 `写入` 及以上（见 §决定 2）。理由是寻址：地址本来就按版本调用（[0035](0035-the-pin-lives-on-the-client-machine.md)），列不出清单就只能靠别人口头告诉他有哪几版。所以 `调用` 打开这一屏时，出现的是**信息与版本两栏**，文件与设置不画。
   - **详情 / 正文 / 单个文件** → `browse`（这正是「网页上也能打开」那条能力）
   - **草稿**（版本列表里的 `draft` 行、以及草稿的正文与文件）→ `write` 及以上
   - **diff** → `write`。它是作者的工具（「上线这一版会带来什么」），梯子没有把「比较两版」列进 `浏览` 的能力
   - **设置那一栏**（常规 / 协作者 / 详细信息）→ 各自的档已经够高（`admin`）；不够档的人那一栏**不渲染**。**页底的危险区域（删除）单独再降一档**：只有所有者看得见（[0050](0050-deleting-a-skill-can-be-undone.md)）
3. **作者面的列表仍是 `write`。** `GET /web/skills` 问的是「**我能以作者身份参与**哪些 skill」（自己拥有的，以及被授 `write` 及以上的），不是一个浏览面。于是「浏览」档的人**不会在控制台里被列出来**——他是**拿着地址打开**的（那是「公开」的含义：拿到地址就能打开）。
4. **消费面一个字不改**：仍然只给 `published`。
5. **已上线内容的字节不随人变。** `@1.2.3` 对所有够得到它的人是同一份字节；按档位变的是**你能看到哪些版本**，不是**你看到的那一版的字节**。

## 理由

**为什么「按档位分」不等于 0031 当初否掉的那件事。** 0031 §决定 8 要防的是「同一个 URL 因为调用者不同而给出不同内容」——那会让缓存失效、也会让**抄走的地址**在别人手里指向别的东西。本决定不碰那条：地址仍然唯一决定「你拿到哪一版的字节」，而本决定变的是「你**知道有**哪些版本」。两者不是一回事：一个说的是**内容**，一个说的是**目录**。目录因人而异在这个产品里本来就有先例——「调用」档与「浏览」档的整个区别就是**列不列得出目录**，只是那一条今天落在 API 面上。

**为什么把「浏览」档放进作者面，而不是把作者面拆成两页。** 因为那一屏的骨架（文件树）正是「浏览」要的东西，而它的另外两栏（版本、设置）本来就该按档位收敛。拆成两页会造出两个都叫「一个 skill」的地方，而地址只有一个——**两页共用一个地址，等于其中一页是错的**。

**为什么列表不跟着降。** 列表回答「我能以作者身份参与哪些 skill」。只读的人手上没有这样一个集合——给他一份空列表等于告诉他「你没有 skill」，而那句话是关于他的、不是关于这个页面的。**够得到某一个 skill 与拥有一份列表是两件事**，这正是「调用 / 浏览」与「写入」之间的那条线。

## 后果

- **详情端点要按档位过滤版本列表**。这是本版**第二处**「漏一处就静默出错」：漏了呢，`浏览` 档的人会看到草稿的版本号与说明——**还没上线的内容的元数据**，而它们看起来与已上线的那些一模一样（同一个列表、同一个格式）。`browse` 档的响应里**只该有 `published` 的行**。
- **控制台那一屏要能渲染「不是我的」**：要收起来的是**四件**——设置那一栏、头部那颗**指进「设置 › 常规 › 可见性」的徽章**（设置没了它就没有去处）、版本列表里的草稿行、以及按档位收的写侧按钮（上线 / 丢弃 / **查看差异**，`diff` 同样归 `write`）。**这是设计稿要补的第三处**——另外两处是删除入口、以及「已删除」那一份列表与恢复；三处合起来在 [`technical-design.md`](../versions/v5-skill-management/technical-design.md) §分期 末尾那张清单里。
- **`viewer` 不进作者面这条不再成立**（[ADR 0034](0034-skill-level-sharing.md) §后果）。它的后继是 `浏览` 档，而后者**进得去**，只是看不到草稿。0034 的正文不改——那是它当时想的事。
- **一处要顺带确认的行为**：`browse` 档的人打开那一屏时，「当前上线版本」仍然是读得到的（那是 `published`），所以页面不会空——它渲染的是那一个 skill 的公开形态。若那一版**一个都没上线**，页面就是一个空的文件树，而这与消费面在同一情形下的 404 是**两个不同的答案**——那个差别是对的（他确实够得到这个 skill，只是里面还没有公开的东西），但要对得上文案。
