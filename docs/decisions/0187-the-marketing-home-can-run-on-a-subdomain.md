# 0187 · 营销首页可以临时挂在同一注册域的子域上，切回用 301

- **状态**：已采纳（§决定 2 的「切回时 301 到 `www`」与 §决定 3 的「CORS 只放行一个来源」均由 [ADR 0190](0190-the-site-origin-is-an-explicit-list.md) 取代，2026-11-13；其余不变）
- **日期**：2026-11-13
- **所属版本**：[`v63-home-subdomain`](../versions/v63-home-subdomain/README.md)
- **依赖**：[ADR 0086](0086-the-homepage-reads-the-session.md)（首页读取会话、会话 cookie 的 `Domain`、只放行一个 CORS 来源）

## 背景

产品要申请经营性 ICP 许可证，`www.skillmasterai.com` 的页面需要按办证要求改造，改造与审核期间它可能不可用。内测期的访客仍然需要一个能打开、能看介绍、能跳到控制台的首页。

可选做法：

- **A 换成 `skillmasterai.cn`。** 独立顶级域，要新增网站备案；审核期网站不得对外访问；`.cn` 与 `.com` 之间无法共享会话 cookie，CORS 也要另立一套。
- **B 换到同一注册域的子域。** 备案按域名，现有 `skillmasterai.com` 的备案覆盖它的子域（`console.`、`dl.` 就是先例）；会话 cookie 的 `Domain=skillmasterai.com` 天然覆盖；服务端只需把唯一那条 CORS 来源改成新入口。
- **C 维持 `www` 不动。** 与办证安排冲突。

2026-11-13 所有者选 B，子域定为 `home.skillmasterai.com`。

## 决定

1. **临时入口使用同一注册域的子域**，与 `www` 提供同一份静态构建（`/srv/skillmaster/site`）；不为它新建构建、服务或备案。
2. **切回时把临时入口 301 到 `www`**，路径保留；DNS 记录与证书 SAN 长期保留，以后 `www` 维护时还能复用。
3. **CORS 仍然只放行一个来源**，取值随入口切换；不为过渡期扩成多来源。
4. **控制台的站外地址是构建期常量**（`VITE_SITE_URL`），入口切换必须重新出一次控制台，不能只改环境变量。

## 理由

- **为什么否掉 A。** 新增网站备案在审核通过前网站不得对外服务，临时入口在最需要它的时候用不上；跨顶级域也共享不了登录态，等于要为过渡期再立一套身份，正撞上 ADR 0086 明确否掉的「身份有两个来源」。
- **为什么否掉 C。** 办证要求改造页面，而产品在审核期不能没有入口。
- **为什么不扩成两个 CORS 来源。** 那要动 ADR 0086 的契约（来源形状、测试），收益只是让过渡期的 `www` 也显示登录态；而窗口期承担首页的是临时入口，`www` 不承担会话展示。

## 后果

- **域名集合多一个名字**：证书 SAN、每日巡检的解析清单、站点发布探针都要跟；探针必须**按内容比对**而不是只看状态码——443 的默认 server 是 `console`，未知 Host 会拿到 200。
- **P1/P2 不是新的版本目录，但也不是纯运维点击**：它们要改 `deploy/nginx/skillmaster.conf`、`skillmaster-console/.env.production` 与 `site.yml` 的探针，仍然要提交并合并，再手动部署；步骤写在 [`deploy/README.md`](../../deploy/README.md) §首页入口的临时切换。
- **`home` 长期保留**：切回后它只做 301，解析与证书 SAN 不拆。
