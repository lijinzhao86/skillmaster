# 0068 · 一版 skill 的整包导出是一次性快照，不是工作区

- **状态**：已采纳
- **日期**：2026-10-21
- **依赖**：[0001](0001-server-authoritative.md)（服务端权威）、[0005](0005-content-addressing.md)（内容寻址）、[0051](0051-the-author-plane-serves-by-tier.md)（作者面按档可见）、[0054](0054-lifecycle-actions-happen-on-a-version-page.md) §决定 5（已下架只对 `maintain` 可读）、[0063](0063-a-draft-is-addressed-by-a-short-code.md) §决定 3（按版本码寻址）
- **这一条取代 v7 技术设计 §「安全边界：整版字节不出服务端」与 `T-SEC-01` 的绝对禁令**

## 背景

v7 给 CLI 的读路径定过一条硬边界：**整版字节不出服务端**——`cat` / `grep` / `ls` 都是按需读一个文件，服务端从没有把一版打包发出去过。那条边界的理由是当时的 CLI 只有「读一个文件」这一种能力，而「本地有一整份」会把服务端权威变成可被本地改动覆盖的建议。

v9 要的是两件相反方向的事：用户在浏览器或 CLI 里把**一版**取成一个 zip（备份、交接、换机器），以及把一个 zip 带回来变成新版本（没有 CLI 的人也能用网页导入）。如果不做导出，第二条就只能靠用户自己去翻文件；如果做成 pull/push 工作区，就会把「本地有一份」变成常驻事实。

## 决定

1. **导出是一次性快照：一次请求、一个 zip、一份 manifest。** 服务端在一次调用里按钉解析版本、读一次清单、把这一版的字节与一份元数据写进 zip；响应带 `ETag: "sha256:<manifest digest>"` 与 `Content-Length`。它不是工作区：服务端不记录「谁导出过什么」，本地目录归用户自己管。
2. **门槛与「查看文件」同条件**：线上与历史版本 `browse` 及以上，草稿 `write` 及以上，已下架 `maintain` 及以上；**已丢弃不导出**（那一态不展示文件）。`invoke` 仍只能按路径取单文件，不能取整包。
3. **两条平面各一条薄路由**：作者面 `GET /api/v1/author/skills/{ns}/{name}[/versions/{pin}]/archive`（Bearer），浏览器面 `GET /web/skills/{ns}/{name}[@pin]/archive`（会话）。两者调同一个用例。
4. **ADR 0001 / 0035 的「本地不落副本」按字面继续成立**：它们说的是 CLI 的常驻读路径与模型上下文——`cat` 不把整版灌进上下文、CLI 不维护本地镜像。用户显式发起、显式选目录的一次导出不在此列。

## 理由

**为什么保留服务端权威。** 导出的字节来自一份 manifest，manifest 来自 `version_file` 行，行只在提交时写；下载目录里的副本**不是**任何东西的事实来源——改它不会改线上，提交它会产生新版本（或在内容未变时被认成幂等）。这与内容寻址的承诺一致：一版的身份是它的清单，不是某台机器上的文件夹。

**为什么不做 pull/push 同步。** 同步需要一个「本地版本」的概念、冲突规则、以及「哪边是真相」的回答；这三件事都会把服务端权威重新打开。一次性快照只回答「这一版是什么」，把「下一步做什么」留给用户。

**为什么已丢弃不导出。** 产品里那一态不展示文件（快照仍在服务端），给它一个下载入口会把「已丢弃」画成一个还能读的状态。要拿回内容，走恢复或复制成新草稿，而不是下载。

**为什么 `invoke` 不扩大到整包。** 整包是「读到这一版的全部文件」，它与文件清单同档（`browse`）；`invoke` 的承诺是按路径取一个文件，扩大它等于把一条窄权限换成一条宽权限。

## 后果

- v7 技术设计那一节与 `T-SEC-01` 需要在文件头加引用；正文不改（ADR 的价值在于「当时为什么这么想」）。
- 服务端多一条一次性出包的路径：临时文件、失败发生在发字节之前、ETag 与包内容同源。并发导出不设上限，风险写在 v9 TD 的 Q1 里。
- CLI 多一条 `skill download`；网页版本页页头多一条直链。两者都不产生新的状态，也不改变任何线上指针。
- 「整版字节不出服务端」从此不再是绝对禁令，而是**按档、按用户显式动作**的出口；消费面与 `invoke` 不变。
