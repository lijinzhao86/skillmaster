# 0178 · `run` 认同一套版本引用，草稿可在发布前执行

- **状态**：已采纳
- **日期**：2026-11-10
- **所属版本**：[`v57-draft-loop`](../versions/v57-draft-loop/README.md)
- **扩展**：[ADR 0165](0165-run-resolves-inside-scripts.md) §7 的解析路径（裸地址记忆不变，不认的引用多一条作者面回退）
- **依赖**：[ADR 0165](0165-run-resolves-inside-scripts.md)（run 起进程）、[ADR 0164](0164-state-is-tiered-by-what-it-writes.md)（缓存位置）、[ADR 0035](0035-the-pin-lives-on-the-client-machine.md)（钉在本机）

## 背景

`skmr run` 先把地址里的版本交给公开面的 `Metadata`（`X-Skill-Version` 头）。服务端只接受「版本名或 `sha256:` 摘要」，草稿的版本码（如 `JD0T518T`）被 400 拒绝，而且原文透传：

```
X-Skill-Version must be a version name or a sha256: digest, but was 'JD0T518T'
```

而 `read` / `write` / `edit` / `version diff` 走的作者面都认版本码；`skmr skill get <地址>@JD0T518T --all` 2026-11-10 实测成功，整版 ETag 就是该草稿的 digest。

结果是「改草稿 → 冒烟 → 发布」断裂：想测草稿只能先发布，测出问题再发一版。2026-11-09 bilibili 草稿里一行必崩的 bug 就是这样漏出去的——打包进 skill 的脚本从未被执行过。

当时的选项：

1. 给 `run` 加 `--draft` 或单独的草稿通道
2. 放宽公开面的 `X-Skill-Version`，让它也认版本码
3. 命名了版本时先问公开面，公开面不认这个引用就转问作者面

## 决定

1. 要问公开面的 pin（不是合法 `sha256:` 摘要）时，**先问公开面**——已发布版本的离线记忆与现有报错都不变。
2. 公开面答「不认这个引用」（400 `invalid_request`）或「看不见」（404）时，**改由作者面解析 digest**（`GET /author/skills/{ns}/{name}/versions/{pin}` 返回的 `version.digest`），再走现有路径：按 digest 取缓存、执行。触发条件是 **pin 本身**，「调用者写了 `@`」不是条件：`invoke` 记住的草稿码在裸地址的 `run` 里是同一个问题。
3. 执行同意与缓存仍按 digest（ADR 0165 §6、§7 不变）。
4. 作者面答 404、或 403 里表示「不是你的」（`forbidden`）时，说「没有这一版」并给 `skmr skill versions <地址>`；403 里表示「凭据权限不够」（`insufficient_scope`）原样交给凭据那句（换一把带权限的凭据），不判为版本不存在；网络失败说明连不上、5xx 原样上抛——超时不是「版本不存在」。

## 理由

- 版本引用的语法应当在所有命令里一致；用户不该记「哪几个命令认版本码」。
- 作者面本来就只服务作者，草稿不出作者之外。让公开面认识草稿，等于把「草稿存在」告诉一个不需要知道的平面。
- **否掉 `--draft`**：同一个东西两套语法，测试与文档都要翻倍，用户仍然要记「草稿用这个参数」。
- **否掉放宽公开面**：公开面的合同是「已发布内容」，草稿不属于它。

## 后果

- 草稿的代码可以在本机被执行；首次执行仍要 `--yes`，粒度是 digest。
- 草稿绑定的服务凭据照常注入，分两支：**已发布的 skill** 用公开面对裸地址的答案决定是否租约（多一次空 pin 的探测，只在有绑定时多一次租约）；**从未发布**的没有公开答案，探测一次租约（无绑定返回空）。**从未发布分支**的探测租约被拒不中止——只读凭据不该因此跑不了草稿；已发布且公开答案说有绑定时，租约失败仍按 v52 报错中止（那是有绑定的 skill，脚本没有变量跑不了）。
- 缓存目录按草稿 digest；发布后是否命中同一目录，取决于两处 digest 是否相同——**待 T12 验证**，未执行。不一致只影响「发布后再问一次」，不影响正确性。
- 别人拿到草稿版本码仍然解析不到：作者面按可见性拒绝，用户看到的是「没有这一版」。
- 公开面 404、而本机记住的 pin 是草稿码（裸地址）时，也会多一次作者面请求；没有本机记录时路径不变。
