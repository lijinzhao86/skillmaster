# ADR 0098 · grep 的范围是「调用者能读到的版本」

- **状态**：已采纳（取代 [0062](0062-grep-is-a-scoped-scan-not-an-index.md) 里「只搜草稿」那一条范围；扫描方式、不建索引、上限与结果形状的结论全部保留——v34 在结果形状上是**向后兼容的扩展**：新增 `match` 字段与可选的上下文行，旧请求的行为不变，见 [`versions/v34-file-toolbox/technical-design.md`](../versions/v34-file-toolbox/technical-design.md) §接口）
- **日期**：2026-10-27
- **依赖**：[`versions/v22-cli-help-and-prompt/`](../versions/v22-cli-help-and-prompt/README.md)、[0062](0062-grep-is-a-scoped-scan-not-an-index.md)、[0058](0058-a-version-is-readable-or-not.md)（消费面看到的状态）、[0061](0061-what-a-credential-may-do-to-versions.md)（档位）

## 背景

0062 把作者面的 `grep` 限定在**草稿**上：只有 `write` 及以上的调用者、且目标行是 draft 时才扫。当时唯一的在线编辑对象就是草稿，这个范围与「编辑时找一行」的用途一致。

在线创作发展之后，这个范围挡住了最常见的动作：**改一个已发布版本之前，先在它里面找一遍**。今天的做法是 `cat <地址> <文件>… | grep`——把整版字节过用户网络，这正是 0062 自己否掉的「做法 2」；而且多条 `cat` 拼成一条流没有分隔，本机的 `grep` 答不出「命中的是哪个文件」。

同一时期，作者面的另外两个读已经在按档位放行了：`files` 与 `wc` 用同一条 `visibleStates(access)` 规则（草稿要 `write`、已发布要 `browse`、已下架与已丢弃要 `maintain`）。`grep` 是这三个里唯一还只认草稿的。

## 决定

1. **`grep` 对「调用者能读到的版本」生效**，与 `files` / `wc` / `cat` 同一条规则：线上 / 历史 `browse`+、草稿 `write`+、已下架 / 已丢弃 `maintain`+。权限底是 `browse`，低于它 403；行级不可见 404。
2. **pin 的形状与 `wc` 一致**：版本名、内容摘要、版本行 id 都接受，不再只认行 id。
3. **`download` 的拒绝不跟着改**：已丢弃仍不可导出。那是**导出**规则，不是读取规则；`grep` 是读。
4. **其余全部不变**：扫描在服务端、不建索引、512 文件 / 16 MiB 的上限、`-F/-i/-n/-l/--path`、结果截断时说「还有更多」、正则与本地 `grep -E` 的语义差异。

## 理由

- **一条规则比三条好记。** 「能 `cat` 的就能 `grep`」是用户能预期的一句话；给 grep 单独留一条「草稿才行」的例外，会让同一版出现「能 `cat` 不能 `grep`」这种没人推得出来的行为。
- **已丢弃跟随读的规则，而不是导出的规则。** 已丢弃的内容仍然存在、`maintain` 仍能 `cat` 与 `wc`；把它从 grep 里单独排除，是为了一个不成立的类比（「不能下载 = 不能读」）。
- **被否的做法：让 CLI 先把整版拉回来本地匹配。** 0062 已经算过这笔账（16 MiB 过用户网络，10 Mbps 约 13 秒），而且本地不落副本的规矩堵死了缓存这条路。
- **被否的做法：只放宽到已发布，草稿之外保持不变。** 那仍然要两套规则；而且已下架版本恰恰是「我要看看旧版怎么写」时最常搜的地方。

## 后果

- **服务端两处一起改**：控制器的 pin 解析与状态门。只改一处，另一处仍会拒绝——实现时两处必须同时落地，且与 `wc` 共用同一条规则来源。
- **错误码 `grep_requires_draft` 保留但不再产生**：线上错误码不复用；新 CLI 短暂连到旧服务端时仍可能收到，所以 CLI 的映射分支保留，只改措辞。
- **帮助与运行时文案要同步改**：`grep --help` 与 `grepRefusal` 里「只在草稿里搜」的说法会变成假话。
- **升级信号不变**：仍然只有「单份上限抬到几十 MB 以上」或「grep 成为每次编辑都跑的高频操作」时才考虑建索引。
