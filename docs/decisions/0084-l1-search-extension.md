# ADR 0084 · 检索的 L1 扩展：`when_to_use`、多词与公开标签

- **状态**：**部分被取代**——§理由里否决「向量检索」的那一条由 [ADR 0095](0095-semantic-retrieval-is-accepted.md) 取代（2026-10-25）；**其余决定（匹配面、多词取「且」、标签过滤在访问谓词内、排序可解释）仍然有效**
- **日期**：2026-10-23
- **依赖**：[ADR 0006](0006-search-server-side.md)（检索在服务端、只索引 L1、排序可解释）、[ADR 0083](0083-two-tag-layers.md)（两套标签）

## 背景

[ADR 0006](0006-search-server-side.md) 把可检索面定在 L1：`name` / `title` / `description`，不索引正文与文件。这个边界来自安全理由，也来自“索引什么，就必须能解释为什么它被搜到”。

v14 要解决的问题换了一类：用户和 agent 不是找“名字里有关键词的东西”，而是找“能解决我这个问题的东西”。L1 里最贴近“问题”的字段是 `when_to_use`——它今天只被读取、不参与匹配；而公开标签是作者写下的召回词，也没有进检索。只靠 `description`，多词查询会大面积落空；只靠分类，10 个粗货架覆盖不了具体问题。

## 决定

1. **L1 的匹配面扩展为**：`name` + `title` + `description` + **`when_to_use`** + **公开标签名**。
2. **`when_to_use` 是平台元数据**（frontmatter 的字段），不是正文、不是文件；它的来源只有作者提交的清单，因此不违反“不索引正文 / 文件”的安全理由。
3. **多词取“且”**：查询里的每个词都要在匹配面里出现（大小写不敏感的包含匹配）；单词查询与今天同义。
4. **我的标签不参与 `q` 的匹配**，也不进公域检索；它只属于库（[ADR 0083](0083-two-tag-layers.md)）。
5. **公域检索必须有输入**：`q`、公开分类或公开标签至少一个，否则 400；不能整表列（[ADR 0082](0082-public-and-private-with-my-library.md)）。
6. **标签过滤在 SQL 的访问谓词内**，不做结果后过滤——否则分页、计数与权限会各自算一套。
7. **排序可解释、可回归**：公域按相关度，同分按更新时间；没有标签权重、没有个性化。`when_to_use` 与公开标签只增加命中，不改变“为什么它排前面”的说法。

## 理由

- **用户的语言是问题，不是名字。** `when_to_use` 与公开标签是 L1 里最接近问题语言的字段；不匹配它们，检索就永远停在“按名字找”。
- **安全性靠“索引什么”，不靠“索引多少字段”。** 只要仍只索引清单里的元数据、不碰正文与文件，ADR 0006 的理由就成立；扩展字段不改变那个边界。
- **多词取“且”是可解释的。** 每个词都能指着命中的字段说“它在这里出现了”；取“或”会让无关结果混进来，且无法解释。
- **请求时过滤会在分页上出错。** 先把结果取出来再丢，计数与“还有更多”都会与真实可用集合不一致；过滤必须在访问谓词内。
- **不做标签权重。** 权重需要信号与调参，而产品今天没有用量、评分或审核数据；规则可回归，权重不可以。

被否掉的：**索引正文 / 文件**（ADR 0006 的安全理由）；**向量检索**（要独立信号与基础设施，先做可解释的关键词 + 标签）；**标签影响排序权重**（无可解释的信号）；**把 `--my-tag` 放进公域检索**（我的标签只属于库，公域里筛不到东西）；**多词取“或”**（无关结果、无法解释）。

## 后果

- 检索查询（`SkillCatalogRepository` 那条 ILIKE 路径）增加 `when_to_use` 与公开标签名的匹配，以及多词的“且”；必要时补索引，`EXPLAIN` 要能证明过滤走访问谓词。
- 检索回归集要扩一类用例：单关键词、多词、`when_to_use` 命中、公开标签命中、无命中；**只用 name / title / description 的既有查询命中不减少**。
- `skills search` 与 `skills list` 的 `q` 共用同一套匹配面（库内还额外受库与标签过滤约束）。
- [ADR 0006](0006-search-server-side.md) 的 L1 枚举由本 ADR 扩展；不索引正文与文件的决定不变。
