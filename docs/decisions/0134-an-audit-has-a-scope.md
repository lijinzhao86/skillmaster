# 0134 · 审计有范围：只审活文档与本次新增

- **状态**：已采纳
- **日期**：2026-11-02

## 背景

v39 的循环审计跑了 10+ 轮。第 3 轮之后代码不再出 blocker / high，第 4–10 轮几乎全是文档与文案，而且大多是**上一轮修复时新写的句子**被下一轮审出来。根因不是审得不仔细，是**没有范围的审计会把同一批历史文本反复读**：仓库有 345 篇文档、3.6 万行，其中 74% 是版本记录，每读一遍都在读已经冻结的东西。

审计要回答的是"现在这样做对不对"，而不是"过去每一版写得对不对"。过去的事已经由冻结机制保证不再变化——反复审它不产生新结论，只产生新成本。

## 决定

审计分四个范围。**范围由触发条件决定，不由心情决定。**

| 范围 | 触发 | 覆盖 | 不覆盖 |
|---|---|---|---|
| **A · 改动审计** | 每一个 PR | 被改的文件；以及用 `impact.py <被改的事实>` 查出的全部关联项 | 没碰的模块 |
| **B · 版本交付审计** | 一版实现完、上线前 | `current/` 全量 + 本版 delta + 本版新增的 ADR | 旧 ADR 正文、旧版本正文 |
| **C · 结构审计** | 目录 / 轴调整，大规模移动 | 全部文档的**形状**：四件套、索引、链接、归档标记 | 散文内容对不对 |
| **D · 内容审计** | 有人报"`current/` 说的和代码不一样" | **只审被报的那一条事实**及其引用 | 其余一切 |

各范围的要求：

**A**：三道阻断检查全绿（`generate.py --check`、`impact.py --check`、`check_docs.py`）；外加 `check_comments.py <改动的目录>` 必须跑、结果如实写进 PR——它是警告，不阻断（存量注释不可能一版清完）。每条被改的事实都要查一次关联项，逐条确认引用仍成立。产物是 PR 描述里的一张表：**改了什么 / 关联到谁 / 怎么验的**。

**B**：A 的全部，外加验收映射逐条走过、本版新增的 ADR 逐条读过、本版 delta 不重述现状（重述就改成指向 `current/`）。产物写进该版 `test-plan.md` §结果。

**C**：只量形状，不读内容。产物是一条 iteration 记录。

**D**：只审那一处。修 `current/` 或开一条新 ADR，不顺手扩大范围。

**不比较历史，只检查约束。** 旧版本**从不**参与对比——它们只对当时成立，不是基准。旧 ADR 只在新改动**触及它记的事实**时被读，由 `impact.py` 找出，不靠通读。新 ADR 必须写「取代」：要么「无」，要么点名被取代的编号，让约束链显式。

判据一句话：**对比是 O(历史)，查约束是 O(变更)。只做后者。**

**消费发生在设计阶段，不是审计阶段。** 方案设计时先用 `impact.py` 查出相关 ADR 并读它们，把结论写进方案；推翻已有的，就新开一条并写「取代」。审计只确认这条链还在——关联查过、取代声明在、PR 的表填了——不从零复核决定。把 ADR 留到审计时才读，等于把最便宜的一次查阅放到最贵的时候。

三条铁律：

1. **历史永不重审。** 豁免只有两处：ADR 正文与 v40 之前的版本。它们是记录，不是现状；指向已不存在的东西是允许的（`impact.py` 的 `is_frozen()` 按此实现）。`research/`、`target/` 与 `current/` 一样是活文档，不豁免。
2. **以命令为准，不以通读为准。** 能机器验的先跑，人只读它报出的差异。
3. **每条结论附证据。** 没执行就写"未执行"，不用"应该没问题"代替结果。

## 理由

**否掉「每次全量审计」**：成本随仓库总量增长，而仓库只会变大；且它把历史又读了一遍——历史没有变化，读它不会有新结论。

**否掉「只审代码」**：v39 的教训正是第 3 轮之后代码已经干净，剩下的问题全在文档与文案里。不审文档等于放过真正的漂移源。

**否掉「按文件大小决定审不审」**：该审的是**被改动的事实**及其引用，不是文件。一行改动的上限值可能牵动二十处文档。

## 后果

- 审计成本从「仓库总量 × 事实数」变成「变更量 × 新增事实数」。
- 三道阻断检查必须常绿，否则"以命令为准"这条不成立：`generate.py --check`、`impact.py --check`、`check_docs.py`。`check_comments.py` 是第四道，但只警告——它的存量口径写在该脚本的 docstring 里。
- 历史文档里的死引用不再被当作缺陷；反过来，**活文档里的死引用一律是缺陷**，这条界线由 `impact.py` 的 `is_frozen()` 划。
- 一个 PR 没有关联项表，就不算做完 A 范围——这比"审得仔细"更可判定。
