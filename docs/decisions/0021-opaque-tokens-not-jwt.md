# ADR 0021 · 令牌用不透明随机串，不用 JWT

- **状态**：已采纳
- **日期**：2026-10-02
- **依赖**：[ADR 0007](0007-self-built-oauth-as.md)（自建 OAuth 2.1 AS；「令牌只存哈希」与「撤销」都出自那里）

## 背景

[ADR 0007](0007-self-built-oauth-as.md) 定了自建 AS，并写下一句「令牌只存哈希（sha256），数据库泄露不等于令牌泄露」。但**令牌本身长什么样**一直没定，而这是两条完全不同的路：

- **自包含 JWT**：服务端签名，验令牌**不查库**，客户端能读 claims。
- **不透明随机串**：令牌是一段没有含义的随机字节，服务端只存它的哈希，验令牌**查一次库**。

[`technical-design.md`](../versions/v1-hosting/technical-design.md) §4.4 的端点表里那一行 `/.well-known/jwks.json` 一直写着「若用 JWT 签名」——它就是这个问题留下的口子。§3.1 的三条实现约束（只存哈希 / `audience` 必校验 / 刷新轮换）在两条路下都成立，所以它们不构成答案。

**一个让这个问题变清楚的事实**：「只存哈希」这条约束已经把**库里的形状**定死了——两条路都要一列 `token_hash`，因为不透明串存它自己、JWT 也至少要存一个 `jti` 或整串的哈希。所以「JWT 能省一列」是假的；两条路的真正差别只有一处：**验令牌那一步是查库，还是验签。**

## 决定

**令牌是不透明随机串**（密码学安全的随机字节，base64url 编码）。服务端只存它的 `sha256`。

- 验令牌 = `sha256` 后按 `token_hash` 主键查一次，再判 `expires_at`、`revoked_at`、`audience`。
- **不签名、不引入签名密钥、不提供 `/.well-known/jwks.json`**——§4.4 那一行随之失效（MCP 只要求 PRM 必做 + AS 元数据二选一，没有要求 jwks）。

## 理由

**为什么不是 JWT。** JWT 买到的唯一东西是「验令牌不查库」，而它一旦要支持**立即撤销**，这条路就断了：要么再维护一份黑名单（等于又查库，白付了签名的复杂度），要么把 access token 的寿命压到黑名单不再必要。而本项目的撤销需求是硬的——重置密码要**立刻**撤掉那个人的全部凭据（§7 P1 从 M01 那边写的就是「撤销该账号全部会话」，令牌那一半同理）。所以 JWT 在这里是**付了代价、没买到东西**。

**为什么不是「签 JWT 但每次仍查库」。** 这是最差的一条：付了签名的全部代价（密钥、轮换、jwks 的缓存语义），又保留了查库，还多一个「客户端读到的 claims 与服务端实际认定不一致」的失效模式。

**为什么密钥这件事在本项目格外贵。** 签名要一把密钥，还要一套轮换方案，还要处理「客户端缓存了旧 jwks」——而 M01 已经欠着一笔同样的债：`phone-hmac-key` / `phone-enc-key` 两把密钥**今天没有任何轮换方案**，记在 TD §8 问题 13 与 M01 §已知的不精确。在令牌上再添一笔，是明知故犯。

**`audience` 校验不构成理由。** 约束 2（`audience` 必须校验）在不透明串下是一次列比对、在 JWT 下是一次 claim 比对，两边一样简单。

## 后果

- **每个受鉴权的请求多一次按主键的索引查询。** 这是 PostgreSQL 的主键查找，v1 的量级下不构成瓶颈。真的成为瓶颈时的退路是加一层短 TTL 的进程内缓存——**那是一个可以后加的优化，代价是撤销延迟变成 TTL**，而不是现在就要付的复杂度。
- **撤销立刻生效**，于是「重置密码连带撤销全部令牌」这条规则成立。这是本条决定换来的主要东西。
- **令牌的熵成为唯一的安全边界。** 因为存的是**裸 sha256**（不加盐、不加 pepper），一个可枚举的令牌等于没有哈希保护——所以生成必须用 `SecureRandom`，长度必须够（记在实现里，不在本文给数字，因为它随编码一起定）。
- **令牌是 bearer 且没有第二道关**：没有「验签失败」这种东西，任何拿到它的人都能用。所以它只走 `Authorization` 头（[ADR 0007](0007-self-built-oauth-as.md)）、绝不进 query string，也不得出现在日志与错误响应里。
- **`/.well-known/jwks.json` 不做**：TD §4.4 的那一行要改。
- **若将来要让第三方资源服务器离线验令牌**（P2 的 MCP 适配器可能想要），就需要回头加签名——届时应**新增一条 ADR 取代本条**，而不是在实现里悄悄加上。
