# ADR 0013 · 登录凭据与公开身份分离：手机号登录，用户名做 slug

- **状态**：已采纳
- **日期**：2026-10-01
- **依赖**：[ADR 0007](0007-self-built-oauth-as.md)、[ADR 0012](0012-addressing-and-version-pinning.md)、[ADR 0010](0010-storage-in-postgres.md)

## 背景

v1 要自建登录（[ADR 0007](0007-self-built-oauth-as.md)），登录标识有几种常见选法：手机号、邮箱、外部 SSO。国内用户的习惯是手机号 + 密码。

而地址是 `namespace/name[@版本]`（[ADR 0012](0012-addressing-and-version-pinning.md)），第一段是命名空间的 slug。§3.2 原本定「注册时 slug = handle」，而 `handle` 同时又是登录名——于是「登录用什么」这一件事，直接决定了「地址里出现什么」。两者在旧设计里是同一列，必须显式拆开。

三个选项：

1. **手机号即 `handle` 即 slug。** 少一个注册字段，「手机号即账号」符合国内习惯。
2. **手机号只做登录凭据，另设用户名做 slug**：用户名由用户自填，或由系统生成。
3. **不用手机号**，走邮箱或外部 SSO。

## 决定

- 登录标识是**手机号 + 密码**。手机号**不进任何地址**。
- 注册时用户**自填一个用户名**，它是 `app_user.handle`，也是其个人命名空间的 `namespace.slug`（§3.2 那条 `slug = handle` 不变，变的是 `handle` 不再兼任登录名）。
- **用户名不可更改。**
- 注册与找回密码都用**短信验证码证明手机号归属**（阿里云短信）。
- 手机号**不以明文入库**：盲索引（HMAC-SHA256）与密文（AES-GCM）两列。

## 理由

- **slug 是公开面，不是内部标识。** 它出现在每张搜索卡片、详情响应的 `namespace.slug`、每条 `files[].uri`，以及服务端与网关的每一行访问日志里。手机号是个人信息，做 slug 等于把它做成一份公开可爬的目录。**选项 1 因此被否**——这是隐私问题，不是风格问题。
- **选项 3 被否**：邮箱同样是个人信息，理由与上一条相同；而国内用户对「邮箱当账号」的接受度显著低于手机号。外部 SSO 解决的是「不想要密码」，而 v1 要的恰恰是一个能独立成立的自建凭据（[ADR 0007](0007-self-built-oauth-as.md) 已把 SSO 降级成 `identity` 表里的一行，将来接进来只是加一行）。
- **系统生成用户名被否**：用户名会出现在该用户所有 skill 的地址里，是对外展示、也是被口述与转发的一部分。不可猜的随机串让「把这个 skill 的地址发给我同事」不再可行，代价落在每一次分享上。
- **用户名不可改**：地址是版本钉的、会被客户端抄走并长期使用（[ADR 0012](0012-addressing-and-version-pinning.md)）。改 slug 等于让所有已发布地址失效。**这正是「自填」必须配「不可改」的原因**——一次性是它需要用户慎重的理由，不是缺陷，所以注册页必须写明。
- **短信验证码不是额外要求，是「手机号成为唯一凭据」的必然结果**：不证明归属，别人就能用 `13800138000` 注册，而 `UNIQUE` 会把真主人**永久**挡在门外；同时手机号又是找回密码的唯一通道。注册防抢注与找回密码共用这一条依赖。
- **手机号不明文入库**用的是 [ADR 0007](0007-self-built-oauth-as.md) 自己的推理——「令牌只存哈希，数据库泄露不等于令牌泄露」。手机号比令牌更该按这条办。

## 后果

- **引入一个外部依赖**：阿里云短信的签名与模板需审核，因此成为 `prd.md` 验收 #1 的**前置**；短信按条计费，且必须自建防刷（图形验证码、每手机号冷却与日限、每 IP 限流）——服务商自己的频控不够。
- **验证码落在 PostgreSQL 里**（[ADR 0010](0010-storage-in-postgres.md) 定的是唯一状态存储），所以它是一张带 TTL 清理的表，而不是一个缓存组件。哈希只挡到它挡得住的程度：六位数字的哈希本身可枚举，**真正管用的是过期时间与尝试次数上限**。
- **用户名成为一个永久占用的公开标识**，因此需要一套校验（ASCII、长度、保留名）与注册页上的提示——**别用真实姓名或手机号当用户名**。
- **改密码必须撤销该用户全部令牌与会话**，否则「找回密码」等于没找回。
- 登录标识与公开身份分开之后，将来接 SSO 只是 `identity` 表加一行，不动主键。
- 若将来要改回「手机号即 slug」，代价是迁移所有已发布地址。**这正是要现在定下来的原因：现在免费，发布之后不免费。**
