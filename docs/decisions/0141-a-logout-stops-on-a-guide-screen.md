# 0141 · 退出登录后停一页引导

- **状态**：已采纳（收窄 [ADR 0086](0086-the-homepage-reads-the-session.md) §决定 2；§理由 里「`logout` 只清本机」现只对 API 密钥成立，CLI 登录凭据由 [ADR 0142](0142-cli-logout-ends-its-own-server-login.md) 收窄）
- **日期**：2026-11-05
- **依赖**：[ADR 0086](0086-the-homepage-reads-the-session.md)（www 不写、`/logout` 是控制台的路由）、[ADR 0038](0038-default-credential-is-an-api-key.md) §决定 7（API 密钥的 `logout` 只清本机；CLI 登录凭据见 [ADR 0142](0142-cli-logout-ends-its-own-server-login.md)）
- **范围收窄**：收窄 [ADR 0086](0086-the-homepage-reads-the-session.md) §决定 2 的「结束当前会话 → 回到首页」——本 ADR 把它改成「结束当前会话 → 停一页引导 → 由人选择回首页，或把一句话交给 agent 结束 CLI」。0086 的其余决定不变

## 背景

浏览器退出登录结束的只是浏览器会话；这台电脑上的 CLI 凭据是另一份，最长还能用 7 天。今天 `/logout` 只做那一次写，然后立刻把人送回官网，什么都不说。于是人以为「已经全退了」，终端却还在工作，控制台「登录设备」里也还看得见这台机器。

要定的是：退出登录之后，控制台还要不要多说一句话，以及「把 CLI 也退掉」这条路怎么走。

候选有四条：

1. **保持无屏返回**——现状，最省事，但「CLI 仍在用」这句话没有任何地方说。
2. **退出后停一页说明，把「结束 CLI」写成一句交给 agent 的话**——本次采纳。
3. **把人送回登录页，重新登录后到「登录设备」里结束那一行**——能退，但要再登录一次。
4. **退出时把 CLI 也注销**——把两套登录绑在一起。

## 决定

1. **`/logout` 在会话结束后停在引导页**，不再自动跳回首页。
2. **页面说三件事**：这个浏览器上的登录已经结束；这台电脑上的 CLI 如果还没有退出，就仍然可以正常使用；要让它在终端也退出，把一句话交给 agent。
3. **那句话做成可复制的块**：`请运行 skmr logout，让这台电脑退出 SkillMaster 的 CLI 登录。` 按钮是「复制这句话」，复制后变成「已复制」；页面保留「回到首页」。
4. **不把用户送回登录页或「登录设备」**——那要重新登录一次，正是这一版要避免的绕路。
5. **不在这一页提 API 密钥**（2026-11-05 产品负责人决定）：引导只讲 CLI 登录；用 API 密钥的人从「API 密钥」页撤销。

## 理由

- **为什么不默认注销 CLI。** CLI 够不到浏览器的 cookie。它唯一能对服务端说的是「结束这个账号在所有浏览器上的登录」——而浏览器登的可能是另一个账号，这句话就落空；即使账号相同，也会把家里、公司、手机上的网页一起踢掉。`logout` 只清本机这条（ADR 0038 §决定 7）不变。
- **为什么是给 agent 的一句话，而不是把人送回登录页。** 要停的是这台机器上的 CLI；人已经有一个能运行命令的 agent，或者至少有一个终端。把这句话交过去，一步就停；送回登录页则要求他为一个已经完成的目的再登录一次。
- **为什么这句话里要写命令。** 它同时服务两种收件人：agent 照着运行，人自己也可以在终端里运行。只写「帮我退出 CLI」会依赖收件人认识这个产品。
- **为什么第二句是条件句。** 浏览器看不到这台电脑上有没有 CLI 登录，也可能它刚刚已经退出了。把它写成「仍然可以正常使用」是把一个看不到的状态说成事实；条件句只承诺条件成立的那一半，两种情况都成立。
- **为什么页面说「让这台电脑退出」而不是「服务端那份也结束了」。** `skmr logout` 清的是这台机器的凭据，服务端那一行是另一件事；页面只承诺它做得到的。

## 后果

- **官网的「退出登录」不再立即回首页**，多一次点击或一次复制。这是这一页的价钱，写在纸面上而不是藏进实现。
- **`/logout` 从「一次请求 + 重定向」变成「一次请求 + 一屏」**；加载期间仍然什么都不画（`blankWhileLoading` 保留）。
- **`logout-page.test.tsx` 要改**：由「跳官网」改为「停在引导页、复制那句话、回到首页、失败态」。
- **本页交给 agent 的那句话现在完全成立**：同一版由 [ADR 0142](0142-cli-logout-ends-its-own-server-login.md) 让 `skmr logout` 连服务端那次登录一起结束，控制台「登录设备」里那一行当场消失，CLI 输出也不再指回控制台。
- **ADR 0086 的其余决定不变**：www 仍不做任何会话写，退出仍然是 `/logout` 这条控制台路由。
