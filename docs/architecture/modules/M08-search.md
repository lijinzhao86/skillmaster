# M08 · 检索与排序

> **状态**：已实现 · **拥有表**：无 · **对外的发布类型**：无（由用例层调用）

## 职责

只索引 L1 的三个字段（名称、描述、标签），在给定候选集里排序，并给出可解释的相关度。所有权过滤不在它这里：候选集由 M12 的目录接缝给出。

## 边界

- **不做**：判可见性。检索必须把结果限定在调用者有权访问的范围里，而这个谓词是 M12 的一条 SQL。
- **不持有 SQL**：M08 只出谓词（pattern、权重、排序身份、游标），取数经 M12 的目录接缝。
- **不做**：语义向量——那是 M13。

## 对外契约

没有跨模块的发布类型；它被 `SearchPublicSkillsUseCase` / `SearchSkillsUseCase` 调用。

## 为什么这样切

检索是「怎么排」，目录是「有什么、谁能看」。把排序规则与所有权谓词分开，才能保证「搜得到」与「打不开」不会各说各的；代价是搜索每次都要经过 M12 的接缝。
