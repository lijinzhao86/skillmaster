# 账号注销后的数据保留：主流平台怎么写的

> **最后更新**：2026-11-10
> **这一份是什么**：为修改《隐私政策》的注销条款做的公开资料调研。只记平台原文与出处，不代替法务意见；最终条文写进 `skillmaster-site/src/legal/legalText.ts` 与 ADR。

## 结论

**主流平台很少承诺「注销后 30 天内删除全部个人数据」。** 常见写法是三层：

1. 注销后**删除或匿名化**个人数据（「删除或匿名化」并列，不承诺只用删除）；
2. 按数据类型写保留期，或写「实现目的所需的最短时间 / 合理期限」；
3. 明确保留法定例外（网络日志、财税记录、安全与反滥用），并说明备份按轮转周期消失。

给硬天数的平台，天数也不统一：Microsoft 60 天、Google 约 2 个月（备份最多 6 个月）、OpenAI 帮助中心口径 30 天；GitHub 不写天数。

## 逐家

| 平台 | 原文口径（摘译） | 固定天数 |
|---|---|---|
| Google | 删除数据通常约需 **2 个月**（含最长 1 个月恢复期）；加密备份最多 **6 个月**；安全、反欺诈、财税可延长 | 约 2 个月 |
| Microsoft | 请求关闭账户后标记待删除，**等待 60 天**再永久删除 | 60 天 |
| GitHub | 「在账户存续期间及履行合同所需期间」保留；删除请求「尽快删除」，法律、反欺诈、反滥用例外；**不写固定天数** | 无 |
| 飞书 | 注销后删除或匿名化；保留不超过实现目的所需最短时间，超期后「在合理期限内」删除或匿名化；网络日志按法律至少 **6 个月** | 无 |
| 微信 | 注册信息注销后 **60 天**永久删除；聊天记录 **120 小时**；日志 **3 个月**；头像/联系人等保留至删除请求或账户删除 | 按类型 |
| 知乎 | 注销后删除或匿名化；**日志记录保留不少于 6 个月**；法定保存除外 | 日志 ≥6 个月 |
| 语雀 | 注销时停止使用并删除；备份系统在下次轮转时删除；法定保存期除外 | 无 |
| OpenAI | 帮助中心口径：大部分数据在注销后 **30 天内**删除（页面本次 403，未能取原文，属二手来源） | 30 天（未核实原文） |
| Anthropic | 政策只写「保留至合理必要」；聊天记录删除后后台最多 30 天（二手来源） | 政策不写 |

## 对中国法的含义

《个人信息保护法》第 47 条要求「处理目的已实现、无法实现或者为实现处理目的不再必要」时主动删除；个人也可请求删除。行业做法不是不删除，而是：

- 对**账号资料与业务内容**：注销后删除或做去标识化处理；
- 对**网络日志与安全审计记录**：按《网络安全法》等要求保留至少 6 个月，并在此范围内作为法定例外；
- 对**备份**：不逐条编辑，按轮转周期消失；
- 对**去标识化后的记录**：披露「这是去标识化，不是匿名化」，不声称不可复原。

## 对本产品的可用口径

- 账号资料与个人命名空间内容：注销 30 天后删除或去标识化（保持 v56 现有实现）。
- 访问与行为日志：**不随注销删除**。在线明细保留 **90 天**；90 天前的明细归档后最多保留 **3 年**；按人按天的汇总保留 **12 个月**；按法律要求至少保留 **6 个月**。用于安全、审计与产品分析。
- 日志中的账号引用是去标识化的账号 id（账号行只余占位 handle），不含手机号、密码、凭据或同意记录。
